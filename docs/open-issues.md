# 미결 사항

세 플러그인에 흩어져 있던 미확정 항목을 한 곳에 모은다.
**해결되면 해당 항목을 지우고 플러그인 문서의 TODO도 함께 지운다.** 두 곳이 어긋나면 이 문서가 죽는다.

기준일: 2026-09-14 (work-toolkit v0.2.0 / report-maker v0.2.0 / knowledge-notes v0.1.0)

### 확인된 항목 (참고)

아래는 이미 확정되어 문서에 반영됐다. 바뀌면 두 곳을 함께 고친다.

- 출고량은 **SAP 매출수량 기준**. 반품은 항상 별도 표기
- 종별 총출고량 집계 시 **초도배본 제외**
- YES24 수치는 **SCM 기준** (BNK 아님)
- 실판매량 연도 비교는 **YES24 단독 기준**으로 통일. 2021년 구간은 산출 불가
- 그래머존 2022~2025년은 **구판 기준**, 2026년은 신판만

### E-1·E-2 검증 프롬프트 방향

- **정식 보고**: "8월 채널별 실적 정리해서 본부장 보고용으로"
- **애드혹**: "이 엑셀 좀 차트로 보여줘" (두 줄 헤더·소계 행이 섞인 지저분한 파일 첨부)
- **기준 분기**: "총출고 기준으로 다시" — `action_title`까지 다시 계산하는지
- **실패 경로**: Metabase 접근 불가 상황 — 붙여넣기 경로로 전환하는지
- **결론 없음**: 특이사항 없는 날의 일보 — "특이사항 없음"을 명시적으로 쓰는지
- **중복 검사**: 이미 있는 용어를 다른 표기로 요청 — alias 대조로 기존 노트를 보강하는지
