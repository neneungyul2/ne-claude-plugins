# 카피와 콘텐츠를 쓸 때

## 0. 먼저 읽을 것

${CLAUDE_PLUGIN_ROOT}/references/output-rules.md — 공통 출력 규칙. 건너뛰지 않는다.

## 1. 상황 판별

| id | 이럴 때 |
|---|---|
| c-01 | 카피를 시켜도 원하는 문장이 안 나온다 (기준부터 세워야 한다) |
| c-02 | 제품의 어떤 장점을 강조해야 할지 모르겠다 |
| c-03 | 콘텐츠 주제는 있는데 글의 흐름이 안 잡힌다 |
| c-04 | 제목과 첫 문장이 눈길을 끌지 못한다 |
| c-05 | 랜딩페이지에 무엇부터 써야 할지 막힌다 |
| c-06 | 상세페이지가 제품 기능 나열에 그친다 |
| c-07 | 카드뉴스를 장별로 어떻게 구성할지 막힌다 |
| c-08 | 광고 소재는 많은데 무엇을 테스트할지 모르겠다 |

## 2. 절차

1. 위 표에서 맞는 id를 고른다.
2. `${CLAUDE_PLUGIN_ROOT}/references/situations/write-copy/<id>.md` 를 Read 도구로 읽는다.
3. 그 문서의 지침을 그대로 따른다.
4. **표에 없으면** 아래 3장의 공통 원칙으로 처리한다.

## 3. 이 영역의 공통 원칙

- **모호한 기준을 그대로 쓰지 않는다.** "후킹하게", "자연스럽게", "짧게"는 길이·어조·문장 구조·포함 요소 같은 확인 가능한 기준으로 바꾼 뒤 쓴다.
- **제공되지 않은 혜택·수치·후기를 만들지 않는다.** 필요한데 없으면 `근거 필요`로 표시한다.
- **과장 표현과 금지 표현을 걸러낸다.** 최상급, 검증 안 된 수치, 원산지·효능처럼 법적 제약이 있는 표현은 검수 단계에서 점검한다.
- 후보는 **여러 방향으로** 낸다. 같은 말을 조금씩 바꾼 것은 후보가 아니다.
- 길이 제한이 있으면 **글자 수를 지킨다.** 넘기면 후보가 아니라 초안이다.
- 브랜드 톤·금지어가 주어졌으면 마지막에 준수 여부를 점검해 표시한다.
