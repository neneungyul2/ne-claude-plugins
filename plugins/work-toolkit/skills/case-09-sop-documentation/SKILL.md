# CASE 9. 반복 업무 SOP 문서화

## 상황
같은 업무인데도 매번 다르게 처리되어 매번 설명을 다시 해야 하는 상태. 머릿속에만 있던 절차를 문서로 표준화해야 한다.

## 먼저 확인할 정보
1. 업무 정의(한 줄)
2. 목적과 주요 사용자(누가 이 문서를 쓰는지)
3. 현재 업무 흐름(문제점·불편함 포함)
4. 앞으로 적용할 표준 흐름
5. 입력물과 출력물(형식 포함)
6. 반드시 지켜야 할 규칙·정책
7. 자주 발생하는 예외·오류와 대응 방법
8. 완료 기준·검수 방법(체크 가능한 형태)
9. 관리 담당자와 업데이트 주기
10. 문서 형식(위키/문서/표)과 톤(명확/친절/초보자 기준)

## 만들 수 있는 산출물

### A. SOP 초안
- 단계별 절차(번호) + 각 단계의 목적/주의점
- 입력/출력물 표(링크/파일명 규칙 포함 가능)
- 체크리스트(완료 전 확인) 10~15개
- 자주 묻는 질문(FAQ) 5개

### B. 표준화 템플릿/체크리스트
- 실행 체크리스트(착수/진행/완료 3단)
- 입력물 확인 리스트(권한/자료/버전)
- 산출물 템플릿(헤더/목차/필수 항목)
- 검수 체크리스트(품질/정확/형식) 10개

### C. 배포 공지 + 운영 규칙
- 팀 공지(메신저) 1개(왜→뭐가→어떻게 쓰나→링크)
- 온보딩용 5줄 요약(신규 입사자용)
- 문서 운영 룰 5개(업데이트/피드백/버전 관리)
- 정착 확인 체크(2주 후 점검 질문 3개)
