# CASE 5. 회의 후속 정리

## 상황
회의에서 큰 방향만 정해지고 세부 액션은 각자 정리하자고 끝난 상태. 결정된 사항과 액션 아이템부터 정리해야 한다.

## 먼저 확인할 정보
1. 회의 기본 정보 — 회의명/일시/참석자/주제
2. 회의 목적과 내 역할
3. 참고한 자료·메모
4. 핵심 논의 요점(결론 중심)
5. 결정 사항 — 확정/보류 구분
6. 액션 아이템 — 담당·기한·완료 기준
7. 의존성·블로커(승인/자료/타 팀 협조)
8. 이번 회의로 내 업무·일정에 생긴 변화
9. 아직 명확하지 않은 점·후속 합의 필요 사항
10. 출력 형태(회의록/메신저 요약/개인 TO DO)와 톤

## 만들 수 있는 산출물

### A. 요약 + 결정 + 액션 아이템
- 5줄 요약(결론 중심)
- 결정 사항 리스트(확정/미확정 태그)
- 액션 아이템 표(담당/기한/완료 기준/의존성)
- 남은 질문 TOP 5(누구에게 물을지 포함)

### B. 개인 실행 계획(오늘/이번 주)
- 내 할 일을 '오늘/이번 주/대기'로 분류
- 오늘 TOP 3 + 다음 액션(각 1~3개로 쪼개기)
- 이번 주 플랜(마일스톤/버퍼 포함) + 지연 시 재조정 규칙
- 블로커 제거를 위한 요청 메시지 초안 1개(메신저)

### C. 공유 메시지 + 회의록 템플릿
- 메신저 공유 메시지 1개(결정→액션→확인 순)
- 메일 버전 1개(제목 포함, 액션 아이템 표 포함)
- 회의록 템플릿(요약/결정/액션/미결/다음 체크인)
- 리마인드 메시지 1개(무례하지 않게)
