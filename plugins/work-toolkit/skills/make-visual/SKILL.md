# 이미지와 영상을 만들 때

## 0. 먼저 읽을 것

${CLAUDE_PLUGIN_ROOT}/references/output-rules.md — 공통 출력 규칙. 건너뛰지 않는다.

## 1. 상황 판별

| id | 이럴 때 |
|---|---|
| v-01 | 원하는 이미지를 어떻게 설명해야 할지 모르겠다 |
| v-02 | AI로 만든 이미지마다 전형적인 'AI 티'가 난다 |
| v-03 | PPT 내용은 있는데 슬라이드 메시지와 구성이 평범하다 |
| v-04 | 우리 회사 PPT 스타일을 결과물에도 반영하고 싶다 |
| v-05 | 카드뉴스 원고는 있는데 어떻게 디자인할지 막힌다 |
| v-06 | 영상 촬영보다 컷편집과 자막 작업에 더 오래 걸린다 |

## 2. 절차

1. 위 표에서 맞는 id를 고른다.
2. `${CLAUDE_PLUGIN_ROOT}/references/situations/make-visual/<id>.md` 를 Read 도구로 읽는다.
3. 그 문서의 지침을 그대로 따른다.
4. **표에 없으면** 아래 3장의 공통 원칙으로 처리한다.

## 3. 이 영역의 공통 원칙

- **추상적인 표현에 기대지 않는다.** "예쁘게", "감성적으로"는 주제·상황·구도·분위기·유지 요소·제외 요소로 풀어 쓴다.
- **브랜드·제품 정보를 임의로 만들지 않는다.** 로고·색상·제품 형태처럼 정확성이 필요한 것은 `원본 대조 필요`로 표시한다.
- **유지할 것과 바꿀 것을 분리한다.** 수정 지시는 "무엇을 어떻게"까지 구체적인 행동으로 쓴다.
- 슬라이드는 **한 장에 메시지 하나**다.
- 결과물을 그대로 쓰기 전에 사람이 확인할 항목(제품 디테일, 로고, 인물, 수치)을 체크리스트로 남긴다.
- 실제 파일 산출(슬라이드 데크, 차트가 들어간 보고서)이 필요해지면 해당 작업 도구나 `report-maker`로 넘긴다.
