# 찾아보고 분석할 때

## 0. 먼저 읽을 것

${CLAUDE_PLUGIN_ROOT}/references/output-rules.md — 공통 출력 규칙. 건너뛰지 않는다.

## 1. 상황 판별

| id | 이럴 때 |
|---|---|
| r-01 | 자료조사를 해야 하는데 무엇부터 찾아야 할지 막막하다 |
| r-02 | 조사 결과에 출처 없는 숫자와 사례만 있다 |
| r-03 | 보고서·기사 수십 개를 핵심만 빠르게 비교해야 한다 |
| r-04 | 경쟁사 자료는 모았는데 우리 전략으로 연결되지 않는다 |
| r-05 | 리뷰·문의 수백 건에서 핵심 불만과 개선 과제를 찾아야 한다 |
| r-06 | 타깃은 있는데 실제 고객처럼 느껴지는 페르소나가 안 나온다 |

## 2. 절차

1. 위 표에서 맞는 id를 고른다. 두 개가 겹치면 짧게 되물어 확정한다.
2. `${CLAUDE_PLUGIN_ROOT}/references/situations/research-analyze/<id>.md` 를 Read 도구로 읽는다.
3. 그 문서의 지침을 그대로 따른다. 이 파일로 돌아올 필요는 없다.
4. **표에 없으면** 억지로 끼우지 말고 아래 3장의 공통 원칙으로 처리한다.

## 3. 이 영역의 공통 원칙

- **출처 없는 숫자는 쓰지 않는다.** 발표 기관·발행일·원문 링크가 없으면 그 수치는 답변에 넣지 않고 "출처 확인 필요"로 남긴다.
- **사실과 해석을 분리한다.** 원문에서 직접 확인되는 것과 내가 추론한 것을 항상 나눠 쓴다.
- **자료에 없는 내용을 추측으로 채우지 않는다.** 근거가 부족하면 추가로 필요한 자료를 알려준다.
- 서로 다른 출처가 충돌하면 하나로 단정하지 말고 차이와 그 이유를 설명한다.
- 조사는 결론이 아니라 **의사결정에 쓰일 입력**이다. 마지막에 "이 조사로 무엇을 정할 수 있는지"를 한 줄로 적는다.
