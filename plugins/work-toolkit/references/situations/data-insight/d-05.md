# d-05. 성과가 오른 건 알겠는데 무엇 때문인지 설명하지 못할 때

## 이럴 때
그럴듯한 이유 하나로 결론을 내고 넘어간다. 다음에 재현이 안 된다.
**사실과 가설을 분리**하고 검증 계획까지 만든다.

## 먼저 확인할 것
- 성과 지표와 기간별 데이터
- 같은 기간에 바뀐 캠페인·제품·운영 요소
- 비교군 또는 이전 기간
- 유입·전환 등 세부 지표
- 이미 확인한 사실

## 진행
**성과 변화와 동시에 발생한 현상을 원인으로 단정하지 않는다.**
데이터에서 확인되는 사실, 가능한 원인 가설, 추가 검증이 필요한 내용을 분리한다.
각 가설이 맞을 때와 틀릴 때 관찰되어야 할 증거를 제시한다.
판단에 필요한 데이터가 없다면 임의의 수치를 만들지 말고 추가로 필요한 데이터를 알려준다.

## 출력
1. **성과 변화 요약** — 언제, 어떤 지표가, 어느 비교 기준 대비 얼마나 변했는지.
2. **확인된 사실** — 현재 데이터만으로 말할 수 있는 사실을 수치와 함께.
3. **원인 가설** — 가능한 가설을 영향도와 검증 가능성 기준으로 우선순위화.
4. **가설별 증거** — 각 가설을 지지하거나 반박할 데이터와 예상 패턴.
5. **추가 데이터** — 원인을 좁히기 위해 필요한 세그먼트·기간·이벤트·비교군 데이터.
6. **검증 계획** — 비용이 적고 빠른 순서로 분석 또는 실험 계획.
7. **현재 결론** — 확정된 내용과 아직 확정할 수 없는 내용을 분리해 보고용으로.

## 주의
- 원인을 하나로 좁히려는 압박을 받더라도 가설 여러 개로 남긴다. 그게 정직한 답이다.
- 계절성·외부 이벤트를 후보에서 빼지 않는다. 가장 자주 놓치는 요인이다.
