# d-03. 엑셀 함수를 찾아도 내 시트에 어떻게 적용할지 모를 때

## 이럴 때
함수 이름은 알겠는데 내 범위와 조건에 맞추다 오류가 난다.
오류가 나면 처음부터 다시 검색한다.

## 먼저 확인할 것
- 작업할 표와 열 이름
- 결과를 넣을 셀
- 계산 조건과 기대 결과
- 사용하는 엑셀 버전
- 현재 수식·오류 메시지 (있다면)

## 진행
사용자가 제공한 시트명, 열, 셀 범위, 엑셀 버전에서 **실제로 작동하는 수식**을 만든다.
범위를 임의로 가정하지 말고, 정보가 부족하면 필요한 셀 구조를 먼저 질문한다.
수식이 왜 작동하는지 초보자도 이해할 수 있게 설명하고, 오류가 날 수 있는 조건과 검증 방법을 알려준다.

## 출력
1. **추천 수식** — 결과 셀에 바로 붙여 넣을 수 있는 완성 수식.
2. **수식 해설** — 함수별 역할과 참조 범위가 의미하는 바를 단계별로.
3. **적용 방법** — 어느 셀에 입력하고 어디까지 복사해야 하는지.
4. **결과 검증** — 예상 결과와 직접 대조할 수 있는 간단한 확인 방법.
5. **오류 점검** — 버전, 데이터 형식, 절대·상대 참조, 빈 셀 때문에 생길 수 있는 오류.
6. **대체 방법** — 같은 결과를 내는 다른 수식이나 피벗·필터 방식이 있다면 장단점과 함께.

## 주의
- 엑셀 버전에 따라 지원되지 않는 함수가 있다. 버전을 모르면 먼저 묻는다.
- 절대 참조와 상대 참조를 틀리면 복사할 때 전부 깨진다. 적용 방법에서 반드시 짚는다.
