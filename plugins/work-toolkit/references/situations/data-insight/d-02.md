# d-02. 날짜·항목명이 제각각이라 분석을 시작조차 못 할 때

## 이럴 때
같은 항목이 표기만 다르고, 날짜 형식이 섞여 있다. 손으로 통일하다 시간이 다 간다.
**정제 규칙에 따라 한 번에 표준화**하고 변경 내역을 남긴다.

## 먼저 확인할 것
- 원본 RAW 데이터 사본
- 분석에 필요한 컬럼
- 날짜·금액·단위 표준 기준
- 결측치 처리 원칙
- 원하는 출력 형식 (CSV·표 등)

## 진행
**원본 행 수와 값을 임의로 바꾸지 않는다.** 분석을 방해하는 형식만 정리한다.
날짜, 항목명, 단위, 공백, 대소문자, 결측치 표기를 일관되게 맞춘다.
의미가 불분명한 값은 추정해 채우지 말고 `확인 필요`로 표시한다.
**원본과 정제본의 차이를 확인할 수 있도록 변경 내역을 남긴다.**

## 출력
1. **데이터 상태 진단** — 컬럼별 형식 불일치, 결측, 중복, 이상값 후보.
2. **정제 규칙** — 컬럼명, 날짜, 숫자·통화, 단위, 텍스트, 결측치 처리 규칙을 표로.
3. **정제 데이터** — 원래 레코드를 추적할 수 있도록 행 ID를 유지하고 요청한 형식으로 전체 출력.
4. **변경 내역** — 수정한 컬럼, 변경 전후 예시, 수정 건수, 적용 규칙.
5. **확인 필요 항목** — 의미가 불분명하거나 사람이 판단해야 할 값을 원본 위치와 함께.
6. **분석 준비 점검** — 필수 컬럼 누락, 중복 키, 단위 혼재 여부를 체크리스트로.

## 주의
- 원본 파일을 덮어쓰지 않는다. 정제본은 새 파일로 만든다.
- 이상값을 조용히 제외하지 않는다. 제외했다면 건수와 이유를 남긴다.
