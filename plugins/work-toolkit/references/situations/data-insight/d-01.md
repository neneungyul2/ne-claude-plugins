# d-01. RAW 데이터는 있는데 어떤 질문을 던져야 할지 모를 때

## 이럴 때
일단 그래프부터 만들고 나서 "그래서?"에서 막힌다.
**의사결정에 필요한 질문**과 지표를 먼저 정한다.

## 먼저 확인할 것
- 분석할 RAW 데이터 또는 컬럼 목록
- 업무·서비스 목표
- 이번 분석으로 결정할 것
- 알고 싶은 대상·기간·범위
- 현재 보고 있는 지표

## 진행
바로 분석하거나 그래프를 만들기 전에, 목표와 데이터 구조를 바탕으로
**먼저 확인해야 할 질문**을 설계한다.
제공된 컬럼으로 답할 수 있는 질문과 추가 데이터가 필요한 질문을 구분한다.
데이터에 없는 사실이나 수치를 추정하지 말고, 지표가 왜 필요하고 어떤 의사결정에 쓰이는지 설명한다.

## 출력
1. **분석 목표** — 이번 분석으로 내려야 할 의사결정을 한 문장으로.
2. **우선 분석 질문** — 중요도 순으로 핵심 질문 5개와 각 질문이 필요한 이유.
3. **핵심 지표** — 지표명, 정의, 계산식, 필요한 컬럼, 해석 시 주의점을 표로.
4. **비교 축** — 분석 목적에 맞는 단계·비교 대상·채널·기간 구간.
5. **데이터 충족 여부** — 각 질문을 현재 데이터로 답할 수 있는지 '가능 / 부분 가능 / 불가'로.
6. **추가로 필요한 데이터** — 부족한 컬럼과 수집 이유를 우선순위로.
7. **분석 순서** — 가장 적은 작업으로 중요한 판단에 도달하는 순서.

## 주의
- 지표 정의가 부서마다 다를 수 있다. 사내 정의 문서가 있으면 참조하고 복사하지 않는다.
- 답이 나와도 행동이 바뀌지 않는 질문은 뺀다.
