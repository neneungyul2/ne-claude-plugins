# v-04. 우리 회사 PPT 스타일을 결과물에도 반영하고 싶을 때

## 이럴 때
기본 템플릿으로 만들면 우리 회사 문서처럼 보이지 않는다.
기존 슬라이드에서 **재사용 가능한 스타일 규칙**을 추출한다.

## 먼저 확인할 것
- 기존 우수 슬라이드 5~10장
- 새 PPT의 목차·원문
- 발표 목적·대상
- 고정 브랜드 요소 (로고·색상·폰트)
- 결과물 형식·비율 (예: 16:9)

## 진행
기존 슬라이드의 **내용을 복사하지 말고 디자인 규칙만 추출**한다.
실제로 관찰되는 규칙과 추정한 규칙을 구분하고, 색상·폰트·간격을 확인할 수 없으면
임의로 확정하지 말고 `확인 필요`로 표시한다.

## 출력
1. **회사 스타일 시그니처** — 레이아웃, 색상, 타이포그래피, 이미지 사용 방식의 특징.
2. **레이아웃 패턴** — 표지, 섹션 구분, 텍스트 중심, 비교, 데이터, 마무리 패턴을 4~6개로.
3. **컬러 팔레트** — 관찰 가능한 색상을 역할별로. 확인 가능하면 HEX 값 표기.
4. **폰트 위계** — 제목·소제목·본문·캡션의 크기, 굵기, 정렬 원칙.
5. **요소 규칙** — 여백, 그리드, 도형, 아이콘, 사진, 차트의 사용 원칙.
6. **재사용 스타일 가이드** — 다음 PPT에도 복사해 쓸 수 있는 짧은 디자인 지시문.
7. **새 슬라이드 적용안** — 새 목차의 각 슬라이드에 어떤 레이아웃 패턴을 적용할지.
8. **이탈·검수 항목** — 회사 스타일과 어긋날 수 있는 요소와 사람이 최종 확인할 부분.

## 주의
- 추출한 규칙이 우수 슬라이드에서만 관찰된 것인지, 회사 전체 표준인지 구분해 표시한다.
- 로고 규정·색상 코드는 브랜드 가이드가 원본이다. 추정값으로 덮어쓰지 않는다.
