# v-05. 카드뉴스 원고는 있는데 어떻게 디자인할지 막힐 때

## 이럴 때
페이지마다 감으로 배치해 톤이 제각각이다.
**카드 역할에 맞는 반복 가능한 레이아웃**을 설계한다.

## 먼저 확인할 것
- 확정된 카드별 원고
- 채널·규격·카드 수 (예: 인스타그램 1080×1350·8장)
- 브랜드 예시·색상·폰트
- 사용 가능한 이미지·아이콘
- 고정 행동 유도·로고

## 진행
**원고의 의미와 순서는 유지**하고, 명백한 오탈자 외에는 문장을 임의로 다시 쓰지 않는다.
페이지마다 하나의 시각적 중심을 만들고, 제공되지 않은 브랜드 규칙은 추측하지 말고 `확인 필요`로 표시한다.
모든 카드가 같은 디자인 시스템 안에서 변주되도록 설계한다.

## 출력
1. **전체 디자인 콘셉트** — 콘텐츠의 메시지와 브랜드에 맞는 분위기를 한 문장으로.
2. **공통 디자인 토큰** — 배경색, 강조색, 폰트 위계, 여백, 모서리, 그림자 규칙.
3. **페이지별 디자인 설계** — 카드 번호, 카드 역할, 시각적 중심, 레이아웃, 이미지·아이콘, 강조 문구를 표로.
4. **반복 레이아웃 세트** — 훅, 문제 제기, 리스트, 비교, 단계, 증거, 행동 유도에 쓸 레이아웃 패턴.
5. **이미지 방향** — 각 카드에 사진·일러스트·도형 중 무엇이 적합한지와 생성·검색 키워드.
6. **제작 사양** — 규격, 안전 여백, 글자 수, 정렬, 페이지 번호, 로고 위치.
7. **일관성 점검** — 색상, 폰트, 위계, 행동 유도, 카드 간 리듬이 유지되는지 체크리스트로.

## 주의
- 카드별로 다른 레이아웃을 만들면 시리즈로 안 읽힌다. 패턴 4~6개 안에서 변주한다.
- 안전 여백을 지키지 않으면 플랫폼에서 잘린다.
