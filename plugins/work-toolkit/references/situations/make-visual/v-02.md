# v-02. AI로 만든 이미지마다 전형적인 'AI 티'가 날 때

## 이럴 때
완벽한데 부자연스럽다. 무작정 재생성하면 같은 문제가 반복된다.
**어색한 원인을 짚어** 수정 지시로 바꾼다.

## 먼저 확인할 것
- 생성한 이미지 (파일 또는 화면 캡처)
- 사용 목적·타깃
- 의도한 장면·분위기
- 반드시 유지할 요소 (예: 제품 형태·브랜드 컬러)
- 마음에 들지 않는 요소 (예: 정면 응시·매끈한 피부)

## 진행
이미지에서 **실제로 관찰되는 요소만 근거로 진단**한다.
도구 내부 원인을 단정하지 말고, 상황 정보 부족·카메라를 의식한 구도·과도한 완벽함의 관점에서 수정 방향을 제안한다.
제품 형태나 로고처럼 정확성이 필요한 부분은 임의로 바꾸지 말고 `원본 대조 필요`로 표시한다.

## 출력
1. **현재 이미지 진단** — 자연스러움을 해치는 요소를 중요도 순으로 3개 이내.
2. **원인별 점검** — 상황 정보, 카메라 시점, 표정·자세, 조명, 피부·재질, 배경의 생활감을 점검.
3. **유지 요소** — 현재 이미지에서 살려야 할 구도, 색감, 제품 디테일.
4. **수정 지시** — 각 문제를 어떤 장면·시점·조명·질감으로 바꿔야 하는지 구체적인 행동 지시로.
5. **수정용 최종 프롬프트** — 원본의 장점은 유지하면서 어색한 부분만 고치도록 하나의 프롬프트로.
6. **네거티브 프롬프트** — 정면 응시, 과한 피부 보정, 균일한 조명, 왜곡된 손 등 제외 요소.
7. **대안 3가지** — 생활감 중심 / 다큐멘터리 중심 / 브랜드 화보 중심의 수정 방향.
8. **최종 확인** — 실제 사용 전에 사람이 확인할 제품·로고·인물 디테일 체크리스트.

## 주의
- 재생성이 아니라 **부분 수정**이 목표다. 잘 나온 요소를 유지 요소로 먼저 고정한다.
- 사람 얼굴·손, 텍스트, 로고는 마지막까지 사람이 확인한다.
