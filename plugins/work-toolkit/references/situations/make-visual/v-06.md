# v-06. 영상 촬영보다 컷편집과 자막 작업에 더 오래 걸릴 때

## 이럴 때
처음부터 끝까지 다시 보며 편집하고, 자막을 한 줄씩 손으로 넣는다.
**자를 구간이 보이는 컷 리스트**와 자막 규칙을 먼저 만든다.

## 먼저 확인할 것
- 촬영본 또는 대본·전사문
- 타임코드 (있다면)
- 영상 목적·타깃·플랫폼
- 목표 길이 (예: 10분 → 3분)
- 유지·삭제 기준 (예: 핵심 사례 유지·말버릇 삭제)
- 자막 톤 레퍼런스

## 진행
**실제 영상을 편집했다고 말하지 않는다.** 촬영본 또는 전사문을 근거로 편집 계획만 만든다.
한숨이나 침묵도 감정·맥락상 필요한 경우에는 무조건 삭제하지 말고 `사람 검토 필요`로 표시한다.
타임코드가 없으면 임의로 시간을 만들지 말고 문장이나 발화 내용을 기준으로 편집 구간을 표시한다.
판단 근거가 부족한 구간은 추가로 필요한 정보를 알려준다.

## 출력
1. **영상의 핵심 메시지** — 영상에서 반드시 남겨야 할 내용을 한 문장으로.
2. **편집 원칙** — 목표 길이, 호흡, 반복 제거, 사례 보존, 자막 밀도의 기준.
3. **컷 후보 목록** — 시작·종료 타임코드(또는 발화 기준), 내용, 삭제·축약 이유, 권장 조치를 표로.
4. **유지 구간** — 핵심 주장, 감정, 전환, 반드시 남겨야 할 사례.
5. **최종 컷 흐름** — 오프닝 → 핵심 내용 → 사례 → 마무리 순서와 예상 러닝타임.
6. **자막 계획** — 기본 자막, 강조 자막, 화면 전환 자막의 문구와 노출 원칙.
7. **사람 검토 목록** — 맥락이 달라질 위험, 고유명사·수치 오인식, 민감 정보, 최종 싱크 확인 항목.

## 주의
- 전사문 기준 편집 계획은 초안이다. 실제 화면과 어긋나는 구간이 반드시 나온다.
- 말버릇 제거가 과하면 사람이 아니라 낭독이 된다. 호흡을 남긴다.
