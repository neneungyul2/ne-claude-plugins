# a-02. 매주 같은 데이터를 복사해 보고서를 다시 만들고 있을 때

## 이럴 때
매주 같은 과정을 반복하는데 보고서마다 형식이 조금씩 다르다.
**같은 기준과 구조로 자동 생성**되게 만든다.

## 먼저 확인할 것
- 데이터가 있는 위치
- 보고서 완성본 예시
- 반드시 볼 핵심 지표
- 보고 주기·수신 채널
- 사람이 확인할 항목

## 진행
데이터 수집부터 보고서 전달까지의 과정을 단계별로 분석해
**자동화할 부분과 사람이 판단할 부분을 분리**한다.
원본 데이터가 없거나 형식이 달라진 경우에는 임의로 채우지 말고
**작업을 멈춘 뒤 알려주는 예외 흐름**을 포함한다.

## 출력
1. **현재 업무 흐름** — 작업 순서, 입력값, 출력값, 반복 시간.
2. **자동화 설계** — 트리거 → 데이터 수집 → 정제·계산 → 요약 → 보고서 생성 → 전달 순서로.
3. **도구별 역할** — 각 단계에 사용할 도구와 연결할 데이터를 표로.
4. **보고서 생성 규칙** — 지표 계산, 증감 표현, 요약 문장, 파일명, 저장 위치 기준.
5. **예외 처리** — 데이터 누락, 수식 오류, 연결 실패, 비정상 수치가 발생했을 때의 대응.
6. **사람의 검수** — 자동 발송 전 반드시 확인할 수치와 문장을 체크리스트로.
7. **테스트 계획** — 샘플 데이터로 검증할 테스트 케이스와 성공 기준.

## 주의
- 자동 발송은 마지막 단계다. 처음에는 초안 생성까지만 자동화하고 발송은 사람이 한다.
- 실제 차트·대시보드가 필요하면 `report-maker` 플러그인으로 넘긴다.
