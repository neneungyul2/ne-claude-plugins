# a-04. 콘텐츠를 만들 때마다 같은 제작 과정을 반복하고 있을 때

## 이럴 때
매번 기획·문체·디자인을 처음부터 다시 정한다.
기존 결과물에서 규칙을 뽑아 **원고만 바꾸면 되는 구조**로 만든다.

## 먼저 확인할 것
- 기존 결과물 3~5세트
- 브랜드 컬러·폰트
- 문체·금지 표현
- 이번 콘텐츠의 주제와 원고
- 최종 파일 규격

## 진행
기존 예시에서 **반복되는 시각·문체 규칙을 분석**해, 다음부터는 원고만 교체해도
같은 품질로 제작할 수 있는 구조를 설계한다.
자동화할 규칙과 사람이 매번 결정해야 할 내용을 분리하고,
텍스트 잘림·브랜드 불일치를 확인하는 검수 단계를 포함한다.

## 출력
1. **브랜드 분석** — 컬러, 폰트, 간격, 구조, 문체 패턴.
2. **재사용 파일 구조** — 원고 / 브랜드 규칙 / 레이아웃 가이드 / 작업 지침으로 나눠 각각에 들어갈 내용.
3. **제작 흐름** — 원고 입력 → 구성 생성 → 출력 → 검수 순서.
4. **단위별 규칙** — 역할, 핵심 주장, 실행 단계, 근거, 행동 유도의 글자 수와 레이아웃 기준.
5. **사람의 결정** — 주제 선정, 근거, 최종 문장처럼 자동화하지 않을 항목.
6. **품질 점검** — 텍스트 잘림, 간격 불균형, 브랜드 불일치, 어색한 표현 체크리스트.
7. **재사용 방법** — 다음 콘텐츠에서 바꿀 파일과 그대로 둘 파일.

## 주의
- 주제 선정과 근거는 자동화하지 않는다. 거기가 콘텐츠의 가치다.
- 규칙을 뽑을 때 "우수 사례"만 보면 편향된다. 평범한 결과물도 함께 본다.
