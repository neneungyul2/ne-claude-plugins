# a-01. 반복 업무는 많은데 무엇부터 자동화해야 할지 모를 때

## 이럴 때
자동화할 일을 감으로 고르거나, 업무 전체를 한 번에 바꾸려다 실패한다.
**효과 기준으로 우선순위**를 정하고 작고 안전한 단계부터 시작한다.

## 먼저 확인할 것
- 반복 업무 목록
- 업무별 빈도·소요 시간
- 실수·지연이 잦은 단계
- 사용하는 툴과 데이터
- 사람이 반드시 판단할 부분

## 진행
업무를 그대로 자동화하려 하지 말고 **조건 → 행동 → 결과**로 쪼갠다.
반복성, 시간 절감 효과, 규칙의 명확성, 실패 위험, 다른 사람·시스템 의존도를 기준으로
가장 먼저 자동화할 업무를 고른다.
**판단이나 승인이 필요한 단계는 사람의 업무로 남긴다.**

## 출력
1. **반복 업무 진단표** — 업무별 빈도, 시간, 규칙성, 위험도, 자동화 적합도.
2. **자동화 우선순위** — 지금 시작할 업무 1개와 선정 근거.
3. **업무 흐름** — 조건 → 행동 → 결과 구조로 현재 과정과 자동화 후 과정을 비교.
4. **역할 분담** — 도구가 맡을 일과 사람이 확인할 일을 구분.
5. **첫 실행안** — 이번 주 안에 시험할 수 있는 최소 단위 자동화와 필요한 도구.
6. **점검 항목** — 실패 가능성, 예외 상황, 중단·수동 전환 기준을 체크리스트로.

## 주의
- 규칙이 글로 정리되지 않은 업무는 자동화 대상이 아니다. a-06(SOP)을 먼저 한다.
- 빈도가 낮은데 복잡한 업무는 자동화 효과가 거의 없다. 뒤로 민다.
