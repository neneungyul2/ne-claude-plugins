# c-08. 광고 소재는 많은데 무엇을 테스트할지 모를 때

## 이럴 때
색과 문구를 무작정 바꿔 돌리고, 성과가 좋아도 이유를 모른다.
**가설 하나씩 검증하는** 테스트로 설계한다.

## 먼저 확인할 것
- 기존 소재·카피
- 제품·핵심 타깃
- 현재 성과 데이터 (노출·클릭·전환)
- 테스트 목표·기간·예산
- 고정할 조건 (예: 타깃·랜딩페이지 동일)

## 진행
한 테스트에서 여러 요소를 동시에 바꾸지 말고, **각 안이 하나의 가설만 검증하도록** 설계한다.
데이터가 부족하면 원인을 단정하거나 임의의 수치를 제안하지 말고,
검증할 가설과 추가로 필요한 데이터를 먼저 알려준다.

## 출력
1. **현재 소재 진단** — 성과가 좋은 요소와 약한 요소를 사실과 가설로 나눠서.
2. **핵심 학습 질문** — 이번 테스트로 반드시 답해야 할 질문을 우선순위로.
3. **테스트 가설** — 타깃 심리, 메시지 앵글, 카피, 비주얼 중 검증 가치가 높은 가설 3개.
4. **A/B 테스트 설계** — 가설별 대조군, 실험군, 바꿀 요소, 고정할 요소, 예상 반응을 표로.
5. **소재 초안** — 각 실험군의 메인 카피, 보조 카피, 비주얼 방향.
6. **판단 기준** — 핵심 지표, 보조 지표, 최소 관찰 기간, 유지·중단 기준.
7. **다음 베리에이션** — 가설이 맞았을 때와 틀렸을 때 각각 다음에 만들 소재 방향.

## 주의
- 한 번에 한 가지만 바꾼다. 두 개를 바꾸면 무엇이 효과였는지 알 수 없다.
- 최소 관찰 기간을 정하지 않으면 초기 변동을 결과로 오해한다.
