# c-04. 제목과 첫 문장이 눈길을 끌지 못할 때

## 이럴 때
무난한 제목 하나만 놓고 고민하거나, 반대로 클릭만 노린 과장 제목이 된다.
**내용과 독자 기대가 일치하는** 제목 후보를 여러 각도로 만든다.

## 먼저 확인할 것
- 콘텐츠 초안·요약 (예: 본문 또는 핵심 5줄)
- 채널·노출 위치 (예: 뉴스레터·SNS 첫 장)
- 타깃 독자
- 핵심 혜택·정보 (독자에게 약속하는 것)
- 길이·금지 표현 (예: 30자 이내·과장 금지)

## 진행
본문에 없는 내용을 제목에 추가하지 않는다.
클릭을 위해 효과를 과장하거나 불안을 부풀리지 않는다.
**제목만 보고도 주제와 기대할 수 있는 정보가 드러나게** 한다.

## 출력
1. **콘텐츠의 약속** — 이 콘텐츠가 독자에게 주는 가치를 한 문장으로.
2. **훅 방향** — 질문형, 숫자형, 반전형, 경험형, 문제 직면형 다섯 방향을 정의.
3. **제목 후보** — 각 방향별로 3개씩, 정해진 글자 수 안에서.
4. **첫 문장** — 각 방향의 대표 제목과 자연스럽게 이어지는 첫 문장.
5. **정합성 점검** — 제목이 본문의 실제 내용과 일치하는지, 낚시성·상투어·모호한 표현이 없는지.
6. **최종 추천** — 채널과 타깃에 가장 적합한 제목 3개와 선택 이유.

## 주의
- 본문에 없는 숫자를 제목에 넣지 않는다. 가장 흔한 실수다.
- 다섯 방향 중 이 콘텐츠에 맞지 않는 방향은 이유를 적고 뺀다.
