# c-03. 콘텐츠 주제는 있는데 글의 흐름이 안 잡힐 때

## 이럴 때
주제 한 줄만 있고 목차가 없다. 쓰다 보면 흐름이 흔들린다.
**독자 문제에서 시작해 행동 유도까지** 이어지는 구조를 만든다.

## 먼저 확인할 것
- 채널·형식 (예: 뉴스레터, 블로그)
- 주제·작성 목적
- 타깃 독자와 그들의 문제
- 핵심 주장·근거·사례
- 톤·분량·행동 유도 (예: 실무 톤·2,000자)

## 진행
주제를 단순히 설명하는 글이 아니라 **독자의 문제에서 시작해 핵심 주장과 실행 방법으로 이어지게** 구성한다.
제공되지 않은 사례나 수치는 만들지 말고, 근거가 필요한 부분은 `자료 보완 필요`로 표시한다.

## 출력
1. **한 줄 기획** — 누구의 어떤 문제를 해결하는 콘텐츠인지.
2. **핵심 메시지** — 독자가 글을 읽고 기억해야 할 주장과 얻을 변화.
3. **이야기 흐름** — '훅 → 문제 상황 → 핵심 인사이트 → 실행 방법 → 사례·근거 → 정리·행동 유도' 순서로 목차 설계.
4. **섹션별 역할** — 각 섹션이 답해야 할 독자의 질문과 반드시 담을 내용.
5. **본문 초안** — 정해진 톤과 분량에 맞춰 섹션별로.
6. **도입부 초안** — 제목 5개와 첫 문단 3개를 서로 다른 각도로.
7. **최종 점검** — 흐름이 끊기는 부분, 반복 내용, 근거가 부족한 문장.

## 주의
- 목차를 먼저 확정하고 본문을 쓴다. 반대로 하면 두 번 쓴다.
- 사례가 없으면 `자료 보완 필요`로 두고 넘어간다. 만들어낸 사례가 가장 위험하다.
