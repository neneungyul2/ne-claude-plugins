# c-06. 상세페이지가 제품 기능 나열에 그칠 때

## 이럴 때
소재·크기·사용법만 적혀 있고, 고객이 얻는 변화가 안 보인다.
기능을 **혜택과 믿을 근거**로 연결한다.

## 먼저 확인할 것
- 제품 사실·스펙
- 타깃과 사용 상황
- 차별점 (경쟁 제품 대비)
- 리뷰·검증 근거
- 필수·금지 표현 (예: 원산지 고지, 최상급 표현 금지)

## 진행
기능을 그대로 나열하지 말고 **'기능 → 고객 혜택 → 믿을 근거'** 로 연결한다.
확인되지 않은 효과·수치·후기는 만들지 말고 비어 있는 정보는 `확인 필요`로 남긴다.

## 출력
1. **사실과 근거 목록** — 확인된 사실, 활용 가능한 근거, 추가 확인이 필요한 내용을 구분.
2. **고객 문제와 변화** — 구매 전 불편과 제품 사용 후 기대하는 변화.
3. **기능·혜택·근거 표** — 각 기능이 어떤 혜택을 주며 무엇으로 증명할 수 있는지.
4. **상세페이지 흐름** — '히어로 → 문제 상황 → 사용 장면 → 핵심 강점 → 상세 기능 → 근거·리뷰 → 사용법 → 자주 묻는 질문 → 행동 유도' 순서.
5. **섹션별 완성 카피** — 각 섹션의 헤드라인, 설명 문구, 강조할 수치·근거.
6. **이탈 방지 정보** — 배송, 교환·환불, 사용 조건 등 구매 전 확인할 내용.
7. **최종 검수** — 과장 표현, 근거 없는 최상급, 기능 반복, 필수 정보 누락.

## 주의
- 필수 표기(원산지·인증·주의사항)는 검수 단계에서 반드시 확인한다.
- "업계 최고" 같은 최상급은 근거 문서가 없으면 삭제한다.
