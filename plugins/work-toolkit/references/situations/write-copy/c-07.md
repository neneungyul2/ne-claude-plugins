# c-07. 카드뉴스를 장별로 어떻게 구성할지 막힐 때

## 이럴 때
한 장에 내용을 몰아넣거나, 첫 장만 강하고 중간에 이탈한다.
**장마다 메시지 하나**로 나누고 다음 장을 넘기게 만든다.

## 먼저 확인할 것
- 주제·핵심 주장
- 타깃·독자 문제
- 채널과 카드 수 (예: 인스타그램 8장)
- 브랜드 톤·레퍼런스
- 근거와 행동 유도

## 진행
한 카드에 여러 메시지를 넣지 말고, **앞 카드에서 제기한 문제나 궁금증이 다음 카드로 자연스럽게 이어지게** 구성한다.
실제 카드에 들어갈 완성 문장으로 작성하고, 제공되지 않은 수치·사례는 만들지 않는다.

## 출력
1. **한 줄 기획** — 누구에게 어떤 변화를 주는 카드뉴스인지.
2. **전체 스토리** — '훅 → 문제 환기 → 핵심 주장 → 실행 방법 → 사례·근거 → 요약 → 행동 유도' 흐름.
3. **장별 역할** — 각 카드가 전달할 메시지와 다음 장으로 넘기게 할 연결 문장.
4. **장별 완성 문구** — 카드 번호, 역할, 메인 문구, 본문, 시각 키워드를 표로.
5. **훅 후보** — 첫 장 문구를 질문형·숫자형·반전형·도발형·내러티브형으로 각각.
6. **분량·톤 점검** — 카드별 글자 수와 브랜드 톤 준수 여부.
7. **최종본** — 가장 적합한 훅을 적용한 전체 카드 문구를 한 번에 복사할 수 있게.

## 주의
- 마지막 장의 행동 유도가 없으면 콘텐츠가 아니라 게시물이다.
- 카드별 글자 수를 세어 표시한다. 디자인 단계에서 다시 줄이면 메시지가 깨진다.
