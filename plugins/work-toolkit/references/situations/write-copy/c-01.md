# c-01. 카피를 시켜도 원하는 문장이 안 나올 때

## 이럴 때
"후킹하게", "자연스럽게", "짧게" 같은 말로 몇 번씩 다시 요청하게 된다.
모호한 요청을 **확인 가능한 기준**으로 바꾼 뒤 후보를 낸다.

## 먼저 확인할 것
- 사용 목적·형태 (예: 앱 푸시, 배너)
- 타깃·상황 (예: 3개월 미방문 고객)
- 반드시 담을 정보 (예: 할인 금액·사용 기한)
- 길이·톤 (예: 공백 포함 45자·편한 말투)
- 제외 표현 (예: '특별한 혜택', '지금 바로')

## 진행
'후킹하게', '자연스럽게', '짧게'처럼 해석이 달라질 수 있는 기준은 그대로 쓰지 말고
**실제 문장에서 확인할 수 있는 규칙**으로 바꾼다.
제공하지 않은 혜택·수치·사실은 만들지 말고, 정보가 부족하면 먼저 확인 질문을 최대 3개만 한다.

## 출력
1. **카피 브리프** — 목적, 대상, 상황, 핵심 정보, 원하는 행동을 한눈에.
2. **기준 구체화** — 모호한 표현을 길이·어조·문장 구조·포함 요소·제외 요소의 확인 가능한 기준으로 바꿔서.
3. **카피 방향** — 혜택 우선형, 공감형, 궁금증형 세 방향을 정의.
4. **카피 후보** — 각 방향별로 3개씩. 정해진 길이를 지킨다.
5. **기준 점검** — 각 후보가 필수 정보와 제외 조건을 지켰는지 표시.
6. **최종 추천** — 가장 적합한 3개와 선택 이유, 자연스럽게 다듬은 버전.

## 주의
- 글자 수를 넘긴 후보는 후보가 아니다. 세어서 표시한다.
- 같은 말을 어순만 바꾼 것은 다른 방향이 아니다.
