# c-05. 랜딩페이지에 무엇부터 써야 할지 막힐 때

## 이럴 때
혜택과 기능이 뒤섞여 나열되고, 설명은 많은데 행동으로 이어지지 않는다.
**고객이 묻는 순서**대로 설득 흐름을 만든다.

## 먼저 확인할 것
- 제품·프로모션 정보
- 타깃과 핵심 문제
- 혜택·제안 조건 (예: 연간 결제 시 30% 할인)
- 근거·제약 (예: 고객 사례·최소 인원)
- 원하는 행동 (예: 상담 신청·결제)

## 진행
기능과 혜택을 무작정 나열하지 말고, 방문자가
**'나를 위한 제안인가 → 무엇이 달라지나 → 믿을 수 있나 → 조건은 무엇인가 → 지금 무엇을 해야 하나'**
순서로 이해하도록 구성한다. 제공되지 않은 성과 수치나 고객 후기는 만들지 않는다.

## 출력
1. **한 줄 제안** — 타깃, 문제, 핵심 혜택, 행동을 한 문장으로.
2. **고객의 질문** — 방문자가 결제·신청 전 확인할 질문과 반대 이유를 우선순위로.
3. **페이지 흐름** — '히어로 → 문제 공감 → 해결 방식 → 핵심 혜택 → 근거 → 제안 조건 → 자주 묻는 질문 → 행동 유도' 순서로 섹션 설계.
4. **섹션별 카피** — 각 섹션의 역할, 헤드라인, 서브 카피, 포함할 근거.
5. **자주 묻는 질문** — 이탈을 막기 위해 먼저 답해야 할 질문과 답변 초안.
6. **행동 유도** — 방문자의 준비도에 따라 강한 버전과 부담이 낮은 버전을 각각 3개.
7. **설득 점검** — 근거가 부족한 주장, 반복되는 혜택, 흐름이 끊기는 지점.

## 주의
- 히어로 섹션에서 "누구를 위한 것인가"가 안 보이면 나머지는 읽히지 않는다.
- 후기와 수치가 없으면 그 섹션은 비워두고 `근거 필요`로 표시한다.
