# c-02. 제품의 어떤 장점을 강조해야 할지 모를 때

## 이럴 때
한 가지 장점만 말만 바꿔 반복하고 있다.
**고객이 구매하는 이유**를 여러 심리로 나눠 소구 범위를 넓힌다.

## 먼저 확인할 것
- 제품·핵심 기능
- 타깃·페인포인트
- 차별점과 근거
- 매체·형식 (예: 메타 이미지 광고)
- 금지·미확인 표현 (예: '최고', 검증 전 수치)

## 진행
같은 장점을 말만 바꿔 반복하지 말고, 고객이 구매하는 이유를
**열망형 · 기술형 · 사회적 증거형 · 가격 인식형 · 문제 해결형** 5가지 심리 앵글로 나눈다.
확인되지 않은 수치나 후기, 인증은 만들지 말고 `근거 필요`로 표시한다.

## 출력
1. **타깃의 구매 동기** — 고객이 해결하려는 문제와 얻고 싶은 변화를 한 문장씩.
2. **앵글별 가설** — 5가지 앵글이 이 제품에서 어떤 반응을 검증하는지.
3. **광고 카피 세트** — 앵글별로 '메인 카피 + 보조 카피 + 행동 유도' 3세트씩.
4. **근거 점검** — 각 카피에 필요한 수치·리뷰·비교 근거와 현재 확인 여부.
5. **우선 테스트 후보** — 가장 먼저 테스트할 타깃 3개와 예상 반응, 선택 이유.
6. **표현 검수** — 과장, 중복, 모호한 수식어를 걷어낸 최종안.

## 주의
- 5개 앵글을 억지로 다 채우지 않는다. 제품에 맞지 않는 앵글은 그 이유를 적고 뺀다.
- `근거 필요`가 붙은 카피는 그대로 집행하지 않는다.
