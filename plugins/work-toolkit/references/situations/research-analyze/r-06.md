# r-06. 타깃은 있는데 실제 고객처럼 느껴지는 페르소나가 안 나올 때

## 이럴 때
'20~40대 직장인' 같은 넓은 타깃만 있고, 하루가 그려지지 않는다.
**구매 이유가 보이는** 페르소나로 바꾼다.

## 먼저 확인할 것
- 제품·서비스 (예: 중등 영어 문법 교재)
- 타깃 정보 (예: 중학생 자녀를 둔 학부모)
- 고객 근거 (리뷰·인터뷰·구매 데이터)
- 활용 목적 (예: 광고 메시지·콘텐츠 기획)

## 진행
막연한 인구통계나 근거 없는 취미를 만들지 말고, 고객 자료에서 확인되는
**행동·욕구·불편·구매 기준**을 중심으로 구체화한다.
근거가 부족한 내용은 사실처럼 단정하지 말고 '가설'로 표시한다.

## 출력
1. **타깃 세분화** — 현재 타깃을 서로 다른 필요와 행동을 가진 3개 집단으로 나누고 구분 기준과 근거.
2. **우선 타깃 선정** — 문제의 크기, 구매 가능성, 제품 적합도, 접근 가능성, 시장성 기준으로 가장 먼저 공략할 타깃.
3. **핵심 페르소나** — 기본 상황과 하루 일과, 목표, 불편, 현재 대안, 구매 기준, 망설이는 이유, 정보 채널과 검색어, 구매 전후 행동, 실제로 할 법한 말.
   **각 판단에는 고객 근거 또는 가설 표시를 붙인다.**
4. **구매 상황 시나리오** — 문제 인식 → 정보 탐색 → 대안 비교 → 구매 결정 → 사용 후 평가 순서로 행동을 설명하고, 각 단계에서 필요한 정보와 설득 메시지.
5. **실무 적용** — 활용 목적에 바로 쓸 핵심 메시지 3개와 피해야 할 메시지 3개.

## 주의
- 페르소나에 이름과 사진을 붙이는 건 마지막이다. 근거 없는 디테일이 늘어난다.
- "가설" 표시가 절반을 넘으면 페르소나가 아니라 상상이다. 고객 근거를 더 모은다.
