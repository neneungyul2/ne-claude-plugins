# r-03. 보고서와 기사 수십 개를 핵심만 빠르게 비교해야 할 때

## 이럴 때
자료마다 따로 읽고 메모하다 보면 요약만 쌓이고 근거가 연결되지 않는다.
여러 자료를 **하나의 비교 기준**으로 한 번에 본다.

## 먼저 확인할 것
- 분석할 자료 (파일·링크 목록)
- 해결할 과제 (예: 신규 채널 진입 판단)
- 비교 기준 (예: 시장 전망·고객 변화·경쟁 구도)
- 원하는 결과물 (예: 비교표·회의 안건)

## 진행
자료를 먼저 모두 읽는다. **자료에 없는 내용은 추측하지 않고**, 근거가 부족하면 추가로 필요한 자료를 알려준다.

## 출력
1. **자료별 핵심 요약** — 각 자료의 주장, 주요 수치, 결론을 3줄 이내로.
2. **비교 분석표**
   | 비교 기준 | 자료별 주장과 근거 | 일치·충돌하는 내용 | 차이가 발생한 이유 | 참고 자료와 인용 위치 |
3. **종합 인사이트** — 공통 흐름 3가지, 예외 또는 반대 신호, 해결할 과제에 직접 영향을 주는 인사이트 3가지.
4. **실무 적용** — 종합 결과를 원하는 결과물 형식으로 바꾸고, 각 제안에 근거 자료와 인용 위치를 표시.
5. **추가 조사** — 현재 자료만으로 판단하기 어려운 내용과 추가로 찾아야 할 자료.

## 주의
- 자료 수가 많으면 먼저 비교 기준을 확정하고 나서 읽는다. 기준 없이 읽으면 두 번 읽게 된다.
- 발행 시점이 다른 자료를 나란히 비교할 때는 시점 차이를 명시한다.
