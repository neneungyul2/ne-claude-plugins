# p-02. 시장·경쟁 자료는 많은데 전략 기획서로 연결되지 않을 때

## 이럴 때
자료를 나열한 문서는 나오는데 "그래서 무엇을 하자"가 없다.
외부 환경과 내부 역량을 연결해 **설득력 있는 구조**를 만든다.

## 먼저 확인할 것
- 기획 주제 (예: 온라인 채널 전환 캠페인)
- 기업 환경 (시장 위치·보유 자원)
- 목적·보고 대상 (예: 경영진 예산 승인)
- 제약 조건 (예: 예산 상한·추가 개발 불가)
- 참고 자료 (시장·경쟁 자료 첨부)

## 진행
자료를 단순히 요약하거나 나열하지 말고, **외부 환경과 내부 역량을 연결해**
보고 대상이 의사결정할 수 있는 기획서 초안을 만든다.
자료에 없는 사실은 추측하지 말고 `확인 필요`로 표시한다.

## 출력
1. **기획 목적** — 해결해야 할 문제, 제안하려는 방향, 필요한 의사결정을 한 문장씩.
2. **외부 환경 분석** — 이번 기획에 실제로 영향을 미치는 정치·경제·사회·기술 요인과 각 요인의 근거·영향.
   **관련 없는 항목은 억지로 채우지 않는다.**
3. **내부·외부 분석** — 강점·약점·기회·위협을 구분하고 각 판단의 근거를 참고 자료와 연결.
4. **전략 도출** — 강점×기회, 강점×위협, 약점×기회, 약점×위협 교차 전략. 막연한 방향이 아니라 구체적 실행 지침으로.
5. **기획서 구조** — 배경 → 문제 → 분석 → 전략 → 실행 계획 → 기대효과 → 요청 사항 순서로 목차와 각 장의 핵심 메시지.
6. **논리 점검** — 근거가 부족한 주장, 앞뒤가 연결되지 않는 부분, 보고 대상이 반박할 만한 지점을 보완 질문과 함께.

## 주의
- 프레임워크(PEST·SWOT)는 칸을 채우려고 쓰는 게 아니다. 빈칸은 빈칸으로 둔다.
- 경영진 보고는 "무엇을 결정해달라"가 명확해야 한다. 그게 없으면 공유 자료이지 기획서가 아니다.
