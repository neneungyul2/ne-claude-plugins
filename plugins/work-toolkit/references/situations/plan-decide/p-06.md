# p-06. 여러 선택지 중 무엇을 고를지 판단 기준이 없을 때

## 이럴 때
"이게 더 좋아 보인다"는 의견만 오가고 끝나지 않는다.
**같은 기준으로 비교한 점수표**와 근거가 분명한 추천안을 만든다.

## 먼저 확인할 것
- 결정할 문제 (예: 신규 채널 진입 방식)
- 비교할 선택지 (예: 제휴·직접 운영·위탁)
- 목표·필수 조건 (예: 6개월 내 오픈)
- 자원·위험 요소 (예산·인력·규제)

## 진행
**처음부터 하나를 추천하지 않는다.** 평가 기준과 가중치를 먼저 설계한 뒤 모든 선택지를 같은 조건으로 비교한다.
근거가 부족한 항목은 임의로 점수를 매기지 말고 `평가 보류`로 표시한 뒤, 판단에 필요한 정보를 알려준다.

## 출력
1. **결정 정의** — 결정해야 할 내용, 목표, 선택 가능한 범위, 결정 기한.
2. **평가 기준** — 목표 적합도, 기대효과, 비용, 실행 기간, 실행 난이도, 위험, 되돌릴 수 있는 정도를 검토해 필요한 기준을 선정.
   각 기준의 정의와 가중치 합계가 100%가 되도록 설정.
3. **선택지 비교** — 근거가 확인된 항목만 기준별 5점 만점으로 평가하고, 점수의 근거와 확인이 필요한 정보를 표로.
4. **민감도 검토** — 가중치가 달라졌을 때 추천 결과가 바뀌는지 확인하고, 결론을 가장 크게 좌우하는 기준.
5. **추천안** — 1순위와 차선책, 추천 이유, 포기해야 할 것, 주요 위험과 보완책.
6. **의사결정 메모** — 보고자가 바로 검토할 수 있도록 '결론 → 핵심 근거 3개 → 위험 → 다음 행동' 순서로 5줄 이내.

## 주의
- 가중치를 결론에 맞춰 조정하지 않는다. 민감도 검토가 그걸 잡아낸다.
- 되돌릴 수 있는 결정은 빨리 정하고, 되돌릴 수 없는 결정에 검토 시간을 쓴다.
