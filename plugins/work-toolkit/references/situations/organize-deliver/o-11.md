# o-11. 내가 한 일의 성과를 근거와 함께 정리해 공유해야 할 때

## 이럴 때
바쁘게 일한 것 같은데 하나로 묶어 어필하려니 딱 떨어지는 게 없다.
다 보여주기보다 **성과와 근거가 분명한 것만** 고른다.

## 먼저 확인할 것
- 역할과 범위 (기간 + 내 역할)
- 목표·기대치 (달성 기준)
- 핵심 성과 3~5개 (결과 중심)
- 기여 방식 (내가 실제로 한 행동·판단)
- 근거 자료 (데이터·산출물·피드백)
- 영향 범위 (조직·팀·고객·비용·품질)
- 과정의 어려움·제약과 극복 방식
- 실패·리스크에서 얻은 교훈
- 다음 목표·개선 제안

## 진행
**과장하지 않는다.** 근거가 없는 성과는 만들지 말고, 사용자가 제공한 사실만으로 구성한다.

## 출력 (아래 셋 중 하나)

### A. 1페이지 성과 요약
1. **요약** — 5줄.
2. **성과 3개** — 각각 무엇 / 임팩트 / 근거.
3. **기여 방식 3개** — 상황 / 행동 / 결과.
4. **교훈 2개 + 다음 액션 2개**.

### B. 사례 중심 정리 (평가·승진 대비)
1. **사례 2~3개** — 각 8~12줄. 상황 → 과제 → 행동 → 결과 순서.
2. **측정 가능한 결과** — 사례별 1줄 요약.
3. **역량 태그** — 사례가 보여주는 역량 3개.

### C. 짧은 성과 공유 메시지
1. **메신저 5줄** — 성과 → 근거 → 영향 → 다음 → 요청·참고.
2. **메일 버전** — 제목 포함, 8~12줄.
3. **지원·결정 요청 문장** 1개(선택).

## 주의
- 수치가 없는 성과는 영향 범위로 대체한다. 없는 수치를 만들지 않는다.
- 팀 성과와 내 기여를 구분해 쓴다. 섞으면 신뢰를 잃는다.
