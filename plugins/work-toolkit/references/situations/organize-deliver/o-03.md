# o-03. 회의는 끝났는데 무엇이 결정됐고 누가 할 일인지 모를 때

## 이럴 때
큰 방향만 정해지고 "각자 정리하자"로 끝났다. 다음 회의에서 같은 이야기가 반복된다.
**결정·할 일·담당자**가 보이는 회의록으로 만든다.

## 먼저 확인할 것
- 회의 기록·녹취 (메모 또는 전사본)
- 회의 목적
- 참석자와 역할
- 기존 일정·제약

## 진행
회의에서 **실제로 합의된 내용과 단순 의견·제안·추정을 구분**한다.
담당자나 마감일이 명확하지 않으면 임의로 채우지 말고 `미정` 또는 `확인 필요`로 표시한다.

## 출력
1. **회의 한 줄 요약** — 무엇을 논의했고 어디까지 결정했는지.
2. **결정사항** — 최종 합의된 내용과 결정 근거.
3. **액션 아이템** — 표로: 해야 할 일, 담당자, 마감일, 완료 기준, 선행 작업.
4. **미결 사항** — 결론이 나지 않았거나 추가 확인이 필요한 쟁점과 다음 결정자.
5. **위험과 일정** — 일정 지연이나 충돌 가능성이 있는 항목과 대응이 필요한 시점.
6. **공유용 회의록** — 참석자에게 바로 보낼 수 있도록 '결정사항 → 할 일 → 미결 사항 → 다음 일정' 순서로 간결하게.

## 개인 실행 계획이 필요하면
- 내 할 일을 오늘 / 이번 주 / 대기로 분류
- 오늘 상위 3개와 각각의 다음 행동
- 블로커 제거를 위한 요청 메시지 초안 1개

## 주의
- "논의했다"와 "결정했다"는 다르다. 섞으면 다음 회의에서 다시 논쟁한다.
- 담당자가 `미정`인 액션 아이템은 회의록 맨 위 미결 사항으로 올린다.
