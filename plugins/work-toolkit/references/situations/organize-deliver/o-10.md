# o-10. 핸드오프가 계속 반려되어 완료 기준(DoD)과 리뷰 규칙을 맞춰야 할 때

## 이럴 때
완료했다고 넘긴 작업이 계속 되돌아온다. 완수 기준을 세우지 않으면 무한 수정에 빠진다.

## 먼저 확인할 것
- 산출물 정의 — 무엇을 핸드오프하는지
- 참여자와 역할 — 요청자·수행자·리뷰어·승인자
- 핸드오프 흐름(단계)
- 입력물 기준 — 시작·검수에 필요한 권한·자료
- 출력물 기준 — 형식·링크·버전
- 완료 정의 기준 — 품질·테스트·문서화, 체크 가능한 형태로
- 검수·리뷰 방식과 응답 시간
- 반려 기준
- 핸드오프 기한과 커뮤니케이션 채널

## 출력 (아래 셋 중 하나)

### A. 완료 기준 체크리스트
1. **DoD 체크리스트** — 10~20개. 단계별(작업·리뷰·승인·인수)로.
2. **반려 기준** — 5~10개. 명확한 조건으로.
3. **증거 요구 항목** — 스크린샷·로그·링크 중 무엇을 첨부해야 하는지.

### B. 인수인계 문서 + 메시지
1. **인수인계 템플릿** — 목적·범위·변경 사항·사용법·주의·검증·다음 액션.
2. **핸드오프 메시지** — 메신저 1개 + 메일 1개.
3. **리뷰어 확인 포인트** — 5개, 체크 질문 형태.

### C. 리뷰·승인 운영 규칙
1. **리뷰 응답 기한 제안** — 초안·최종 각각.
2. **수정 라운드 규칙** — 몇 회까지, 무엇이 '최종'인지.
3. **긴급 이슈 우선 처리 룰**.
4. **합의 공지 메시지** + 요약 5줄.

## 주의
- 체크 불가능한 DoD 항목("품질이 좋을 것")은 쓰지 않는다. 확인 방법이 있는 문장으로 바꾼다.
- 반려 기준이 없으면 반려는 개인 취향이 된다.
