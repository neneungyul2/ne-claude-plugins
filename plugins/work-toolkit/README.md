# work-toolkit

실무에서 반복되는 10가지 커뮤니케이션 상황(우선순위 재조정, 애매한 요청 확인, 일정 재계획,
핸드오프/완료기준, 회의 후속 정리, 이슈 공유, 진행상황 보고, 피드백 반영, SOP 문서화, 성과
정리)에 맞춰 문서·메시지·체크리스트를 만들어주는 스킬 모음.

- `skills/work-helper/` — 상황을 설명하면 10개 case 중 맞는 것을 판별해 안내하는 진입점 스킬.
- `skills/case-01-...` ~ `case-10-...` — 각 상황별 체크리스트와 산출물 3종(A/B/C) 정의.

## 출처

각 case의 "먼저 확인할 정보"·"만들 수 있는 산출물" 구조는 에이블런(ABLEARN)의
〈실무자를 위한 프롬프트 팩〉(정대리 시리즈, CASE 1~10)을 참고해 Claude Code 스킬 형태로
재구성한 것입니다. 원본은 ChatGPT/Claude/Gemini 등에 직접 붙여넣는 채움형 프롬프트였고,
이 플러그인은 그 구조를 스킬이 직접 수행하도록 각색했습니다. 원 자료는 "가공 및 인용 시
출처 명기"를 요구하므로 이 문서에 출처를 남겨둡니다. 사내 용도로만 사용하세요.
