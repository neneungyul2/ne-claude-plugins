# 보고서 규격

**두 유형이 있다.** 1~3절은 신간 보고서, 7절은 기간본 보고서. 4~6·8절은 공통이다.

수신자는 개발팀·제작팀이다. **이 검토의 배경 논의를 모르는 사람이 결론만 보고도 이해**할 수 있어야 한다.
TAM·SAM·SOM 같은 용어에 익숙하지 않은 사람이 섞여 있다고 가정한다.

---

## 1. 섹션 순서

논리 흐름대로 간다. 결론은 맨 위, 근거 데이터는 부록.

```
결론          제작 부수 (종별) + 초도 배본 + 2차 제작 판단 시점
01 수치 기준   모든 결과값이 어떤 단위인지
02 시장 규모   TAM → SAM
03 경쟁 구도   계열별 스택 막대
04 목표 점유율  슬라이더 + 시나리오 표 → SOM → 첫해 수요
05 제작 부수    채널 분해 → 계산 흐름 → 결과
06 경쟁서 범위  토글
07 유의사항
부록          보정계수 + 채널 실측 근거
```

**지켜야 할 순서 규칙**

- 점유율이 먼저, 수요가 그다음, 부수가 마지막이다. 순서가 바뀌면 근거가 결과 뒤에 온다
- 채널 분해는 첫해 수요가 확정된 **뒤**에 온다
- 벤치마크 실측표는 **부록**에 둔다. 본문에 두면 이번 도서의 수치로 오해한다.
  부록에도 "본 교재의 예상치가 아니라 같은 세그먼트의 지난 실적"이라고 적는다

---

## 2. 단위 통일

| 대상 | 단위 |
|---|---|
| 시장 규모 · 수요 · 제작 부수 | **연간 추정 총출고 부수** |
| 경쟁 구도 비교 | YES24 추정 판매량 · 조회 기간 합계 |

경쟁사 실판매는 확보할 수 없어 경쟁 구도만 추정값을 쓴다. **이 사실을 01 항목에 표로 적고**,
각 섹션 제목 오른쪽에 단위 배지를 단다. 총출고 기준은 회색, 추정 기준은 다른 색으로 구분한다.

---

## 3. 필수 인터랙션

### ① 목표 점유율 슬라이더

종별로 하나씩. **min = 보수 시나리오, max = 낙관 시나리오, 기본값 = 기준 시나리오.**
움직이면 SOM·첫해 수요·채널 분해·계산 흐름·결론·시나리오 표가 전부 즉시 바뀐다.

현재 설정이 세 시나리오 중 하나와 일치하면 그 이름을, 아니면 "사용자 설정"을 표시한다.
시나리오 표의 행을 클릭하면 슬라이더가 그 값으로 이동한다. 기준값 복귀 버튼을 둔다.

### ② 경쟁서 범위 토글

애매한 묶음을 켜고 끌 수 있게 한다. 끄면 SAM부터 부수까지 전부 재계산된다.
**화면 우하단 고정 패널로도 접근**할 수 있어야 한다. 문서가 길어 본문 토글만으로는 불편하다.
접은 상태에서도 현재 제작 부수가 보이게 한다.

### ③ 계산 흐름

표의 합계로 보이면 안 된다. 칩과 연산자를 나열한 가로 흐름으로 만든다.

```
기초   [2,400 온라인 수요] ×0.75 → [1,800 초판 반영분]
       + [2,300 초도배본·확정] = [4,100 산출값]   →   4,000부
```

확정 물량 칩은 점선 테두리로 구분한다.

### ④ 용어 툴팁

TAM·SAM·SOM·총출고·추정 판매량에 단다. **`position: fixed`로 만든다.**
CSS `::after` 절대 위치로 만들면 표의 `overflow`에 잘린다.

### ⑤ 계수 모달

단위 배지를 클릭하면 부록의 계수표가 모달로 뜬다. 부록 원본을 복제해 띄워 내용이 어긋나지 않게 한다.
인쇄 시에는 모달을 숨기고 부록이 그대로 출력되게 한다.

## 4. 넣지 않는 것 (공통)

| 항목 | 이유 |
|---|---|
| 수신·발신·작성일·PO·입고일 | 메일 본문에 쓴다. 문서 상단을 차지할 이유가 없다 |
| 제작 사양(판형·용지·색도) | 제작 계획서에 이미 있다 |
| 확인 요청 목록 | 대부분 제작팀 소관이다. 메일로 보낸다 |
| 초도 배본 조정 제안 | 확정값이면 조정 대상이 아니다. 그냥 전제로만 쓴다 |

## 5. 유의사항에 반드시 적을 것 (공통)

**기간본이면 아래도 함께 적는다.**

- 가용재고에서 뺀 창고 목록과 그 수량
- 세트 품목코드 포함 여부
- 계절지수의 표본 연수. 3개년이 안 되면 그 사실
- 구품목코드를 이어 붙였으면 그 사실과 구간
- 미입고분(제작 진행 중)이 확정값인지 미확인인지
- 개정·폐간 예정을 "없음"으로 확인받았는지, 미확인인지

**공통**

- 계수의 표본 크기와 편차 범위
- 벤치마크가 노후 품목이면 그 사실과 방향성
- 자사 기존 품목과의 타깃 중복 (SOM에 잠식분을 반영했는지)
- 목차를 확인하지 않고 명칭으로 분류한 품목
- 중복 등록이 의심되는 ISBN
- 채널 합계가 SAP 순출고와 어긋나는 이유
- 데이터 적재 시작일 때문에 빠진 구간

**숨기지 않는다.** 나중에 지적받는 것보다 먼저 적는 편이 낫다.

## 6. 디자인 (공통)

`report-maker`의 `references/template/base.css`와 같은 계열을 쓴다.
`${CLAUDE_PLUGIN_ROOT}/assets/report-template.html`에 이 플러그인용 골격이 있다.

- 라이트 모드 전용
- 큰 숫자는 세리프, 본문은 산세리프
- 종별로 색을 하나씩 배정하고 끝까지 일관되게 쓴다
- 좌우 정렬을 맞춘다. 설명문에 `max-width`를 걸면 문장이 화면 절반에서 끊겨 이상해 보인다
- `word-break: keep-all`로 어절 단위 줄바꿈
- 표 래퍼에 `overflow-x: auto`를 걸면 세로 스크롤바가 함께 생긴다. `overflow-y: hidden`을 명시한다

## 7. 기간본 보고서

신간 보고서와 **섹션도 인터랙션도 다르다.** 템플릿은 `assets/reprint-template.html`이다.

수신자가 먼저 알고 싶은 것이 다르다. 신간은 "얼마나 팔릴까"지만, 기간본은
**"언제 떨어지나, 언제까지 발주해야 하나"**다. 그래서 결론에 수량과 함께 **날짜**가 들어간다.

### 섹션 순서

```
결론          제작 수량 (종별) + 소진 예상월 + 발주 마감일
01 수치 기준   총출고 / 순출고 / 재고의 기준
02 재고 현황   창고별 · 가용재고 확정 (뺀 창고를 보여준다)
03 출고 추세   연도별 + 월별. 노후화율 g
04 시장 확인   시장이 줄었나 우리가 뺏겼나
05 소진 타임라인  월별 수요 × 재고 잔량 곡선 → 소진 예상월 · 발주 마감일
06 제작 수량   커버 기간 슬라이더 → 필요량 → 잔여 수명 상한 → 결과
07 유의사항
부록          계절지수 · 제작 이력 · 창고 분류
```

**순서 규칙**

- 재고가 먼저, 추세가 그다음, 소진 시점이 그다음, 수량이 마지막이다
- **04 시장 확인은 03 뒤에 온다.** 자사 추세를 먼저 보여주고 그 원인을 시장에서 확인하는
  순서여야 한다. 시장을 먼저 꺼내면 신간 보고서처럼 읽혀 top-down으로 오해한다
- 개정·폐간 상한에 걸렸으면 **06 안에서** 보여준다. 유의사항으로 내리지 않는다.
  수량이 왜 깎였는지가 결론의 절반이다

### 필수 인터랙션

**① 커버 기간 슬라이더** — 개월 수. 종별로 하나씩.
움직이면 필요량·제작 수량·사장 예상 재고·결론이 즉시 바뀐다.
눈금에 **다음 성수기 종료월**을 표시하고 그 값을 기본값으로 둔다.
슬라이더를 끝까지 밀어도 **잔여 수명 상한에서 멈춘다.** 멈추면 왜 멈췄는지 문구로 알린다.

**② 소진 타임라인** — 이 보고서의 중심 도형이다.
가로축은 월, 세로축은 재고 잔량. 재고 곡선이 0을 끊는 지점이 소진 예상월이다.
같은 축에 월별 수요 막대를 깔아 **성수기와 소진 시점의 관계**가 한눈에 보이게 한다.
발주 마감일(소진월 − 리드타임)을 세로 점선으로 긋는다. **이 점선이 오늘보다 왼쪽이면
이미 늦은 것이다. 색을 바꿔 경고한다.**

**③ 개정 예정일 토글** — 상한을 켜고 끌 수 있게 한다.
끄면 수요 기준 수량이, 켜면 상한이 걸린 수량이 나온다. 차이가 곧 개정의 비용이다.
예정일이 "없음"으로 확인된 품목은 토글 자체를 넣지 않고 그 사실을 적는다.

**④ 용어 툴팁 · 계수 모달** — 신간과 같다.
용어는 가용재고·총출고·순출고·노후화율·계절지수·리드타임에 단다.

### 결론에 반드시 들어가는 것

```
제작 수량   0,000부
소진 예상   2026년 0월       ← 날짜다. 부수만 적지 않는다
발주 마감   2026년 0월 00일   ← 리드타임을 뺀 값
```

상한에 걸렸으면 한 줄 더 붙인다.

> 수요 기준 6,000부이나 2027년 1월 개정 예정이라 3,000부로 낮췄습니다. 사장 예상 재고 400부.
