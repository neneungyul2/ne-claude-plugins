# 채널 모델과 부수 산식

**신간 경로 문서다.** 기간본은 채널을 나누지 않는다 — 재고는 채널 구분 없이 하나로 빠지므로
소진 시점 계산에 채널 분해가 필요 없다. 기간본 산식은 `reprint-model.md`를 본다.

다만 1절의 채널 정의는 기간본에서도 쓴다. 출고가 줄었을 때 **어느 채널에서 줄었는지**를 보면
원인 판정(시장 축소 / 점유율 이탈 / 유통 문제)이 빨라진다.

---

## 1. 채널 정의

| 채널 | 소스 | 성격 |
|---|---|---|
| 온라인 4사 | DB3 `mart.actual_sales_daily` — 예스24·교보(온·오프)·알라딘·영풍(온·오프) | 실판매 |
| 쿠팡 | 2025년 이전 SAP 거래처 / 2026년 이후 DB9 `raw.stocked_items` | 출고·입고 |
| 총판 | DB4 `raw.sap_sales` 중 **온라인 5사 거래처 코드를 제외한 나머지** | 출고 |

`LOCAL` 채널은 부분 표본이라 쓰지 않는다. 총판 출고로 갈음한다.

**세 채널의 집계 성격이 다르다.** 합계가 SAP 순출고와 일치하지 않을 수 있다.
비중 산출에는 영향이 없으므로 그대로 두고, 보고서 각주에 남긴다.

## 2. 카테고리별 온라인 비중 (2025.01~2026.07 실측)

| 세그먼트 | 벤치마크 | 온라인 | 총판 |
|---|---|---|---|
| 중학 수능 독해 | 수능 딥독 3종 | 64% | 36% |
| 고등 내신 서술형 | 필히 통하는 2종 | 41% | 59% |

**같은 영어 교재라도 두 배 가까이 차이난다.** 학년이 올라가고 내신·학원 수요가 붙을수록
총판 비중이 커진다. 새 카테고리면 반드시 다시 뽑는다.

신간 첫해는 온라인 비중이 더 높게 나온다. 온라인 선주문·광고로 초기 물량이 나가고
총판 유통은 2년 차부터 자리를 잡기 때문이다. 다만 첫해만 보면 표본이 한쪽에 치우치므로
**반품 사이클을 포함한 연속 구간**을 쓴다.

## 3. 부수 산식 — 초도 배본이 갈림길이다

초도 배본은 영업에서 확정하는 값이다. **추정하지 않는다.** 확정값을 받아서 쓴다.

```
총판 첫해 수요 = 첫해 총수요 × (1 − ONLINE)
```

### 분기 A — 초도 배본 > 총판 첫해 수요

초도 배본이 총판이 한 해에 소화할 양을 이미 넘어선다. 총판 몫을 초도 배본으로 **대체**한다.

```
제작 부수 = 초도 배본 + (첫해 총수요 × ONLINE × K_PRINT)
```

온라인 중심 세그먼트에서 자주 나온다. 위탁이면 초과분은 반품으로 돌아오지만,
제작은 해야 하므로 전액 반영한다.

### 분기 B — 초도 배본 ≤ 총판 첫해 수요

초도 배본이 총판 수요의 일부다. 나머지는 재발주로 나간다. 채널을 나눌 이유가 없다.

```
제작 부수 = 첫해 총수요 × K_PRINT
```

총판 중심 세그먼트에서 자주 나온다. 내신 교재는 시험 주기마다 지사가 재발주하므로
초도 한 번으로 끝나지 않는다.

### 분기 판정을 반드시 보고서에 쓴다

두 도서를 나란히 검토할 때 산식이 달라 보이면 반드시 지적받는다.
**왜 이 도서는 A이고 저 도서는 B인지**를 채널 분해 막대 바로 아래에 한 줄로 적는다.

## 4. 반올림

```
산출값 → 백 단위 반올림 → 천 단위 반올림 → 제작 부수
```

두 단계를 거치는 이유는 **화면에 표시된 숫자와 결과가 일치**하게 하기 위해서다.
산출값 8,499.98을 바로 천 단위로 반올림하면 8,000이 되는데, 화면에는 8,500으로 보여 어긋난다.

JavaScript `Math.round`는 0.5를 올림한다. 파이썬 `round`는 짝수로 내린다.
**검산은 반드시 브라우저와 같은 규칙으로 한다.** 파이썬으로 검산하면 경계값에서 틀린다.

경계값(±100부 이내에서 천 단위가 갈리는 경우)이면 보고서에 민감도를 적는다.

> 목표 점유율을 1%p만 낮춰도 8,000부로 떨어집니다.

---

## 5. 2종 이상일 때

**부수를 억지로 맞추지 않는다.** 종별로 따로 반올림한다.
한 시리즈로 유통되는 세트라도 수요가 다르면 부수가 달라지는 게 맞다.

---

## 6. 2차 제작 트리거

초판에 싣지 않은 25%는 2차 제작으로 대응한다. **판단 시점을 미리 정해 보고서에 적는다.**

| 항목 | 기준 |
|---|---|
| 판단 시점 | 첫 성수기 직후. 재판 리드타임(약 1.5개월)을 빼서 역산한다 |
| 판단 지표 | 출시 후 2개월 누계 출고가 초도 배본의 1.5배를 넘는지 |

입고월과 성수기가 가까울수록 시점을 앞당긴다. 11월 초 입고에 12~2월 성수기면
1월 말이 마지노선이다. 2월 말로 잡으면 3월 신학기 물량을 놓친다.
