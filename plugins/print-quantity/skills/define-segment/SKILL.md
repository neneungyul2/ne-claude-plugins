# 세그먼트 확정 (define-segment)

**데이터를 열기 전에 돈다.** 여기가 틀리면 뒤의 계산이 아무리 정교해도 전부 틀린다.

## 0. 먼저 읽을 것

- `${CLAUDE_PLUGIN_ROOT}/references/segmentation.md` — **필수**

## 1. 제작 계획서에서 뽑는다

첨부된 pptx·xlsx를 먼저 읽는다. 물어보기 전에 읽는다.

| 뽑을 것 | 쓰이는 곳 |
|---|---|
| 서명 · 종 수 · 권별 명칭 | 세그먼트 축 |
| 판매용 / 연구용 부수 | 비교 대상 |
| 본문·워크북·해설 페이지 수 | 권별 위계 판단 보조 |
| 하판일 · 입고 희망일 | 2차 제작 트리거 역산 |

페이지 수 차이가 크면(예: 160p vs 256p) 권별 위계가 있다는 신호다.

## 2. 대상과 콘셉트를 분리해 적는다

```
대상   : 중2 ~ 중3
콘셉트 : 수능 독해 입문 · 유형 학습
권별   : 기초 독해(구조+유형+미니모의고사) / 유형 독해(유형+미니모의고사)
```

광고 페이지나 시리즈 소개가 있으면 여기서 권별 구성을 확인한다.
자사 제품맵이 있으면 대조하되, **제품맵의 분류를 그대로 믿지 않는다.**

## 3. 반드시 묻는 것

- **초도 배본 수량이 확정됐습니까. 위탁입니까 매절입니까**
- **같은 세그먼트의 자사 기존 품목이 있습니까. 폐간입니까 병행입니까**

두 번째 답이 없으면 진행하지 않는다. 승계인지 병행인지에 따라 목표 점유율이 달라진다.

## 4. 산출물

다음 단계로 넘길 브리프를 짧게 남긴다.

```
대상 도서   : <서명> <n>종
세그먼트    : <대상> × <콘셉트>
권별 위계   : <1단계> / <2단계>
초도 배본   : <수량>부 (확정 / 미정, 위탁 / 매절)
자사 기존   : <품목> (폐간 예정 / 병행)
비교 기준   : 계획 <수량>부
```

---

## 5. 기간본이면 — 여기서 함께 확정한다

세그먼트 확정은 신간과 같다. 아래 네 가지를 **추가로** 받아야 3단계가 돈다.

| 확인할 것 | 없으면 |
|---|---|
| **SAP 품목코드 / ISBN** | 실적·재고를 못 뽑는다 |
| **개정·폐간 예정일** | **"없음"까지 확인받는다.** 모른다로 넘어가지 않는다 |
| **제작 리드타임** | 제작팀 확인값. 못 받으면 1.5개월 + 미확인 표기 |
| **미입고분** | 제작 진행 중 물량. 데이터에 없다. 물어야 안다 |

추가로 두 가지를 스스로 확인한다.

- **세트 구성품인지** — 세트로도 팔리면 세트 품목코드 판매분이 수요에 들어간다
- **개정·리뉴얼로 품목코드가 바뀐 이력** — 계절지수를 3개년으로 만들려면 이어 붙여야 한다

**개정 예정일 하나로 수량이 절반이 된다.** 이걸 확인하지 않고 낸 숫자는 나중에 전부 틀린다.

### 기간본 브리프

```
대상 품목   : <서명> <n>종
품목코드    : <코드 목록> (세트 <있음/없음>, 구품목 <있음/없음>)
세그먼트    : <대상> × <콘셉트>
개정·폐간   : <연월> 예정 / 없음 (확인받음)
리드타임    : <n>개월 (제작팀 확인 / 미확인)
미입고분    : <수량>부 (<연월> 입고 예정) / 없음 / 미확인
```
