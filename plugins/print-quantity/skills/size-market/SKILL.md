# 시장 규모 산출 (size-market)

**신간·기간본 공통 단계다.** 하는 일은 같지만 쓰는 곳이 다르다.

| | 목적 |
|---|---|
| 신간 | SAM을 잡아 첫해 수요를 역산한다 |
| 기간본 | **자사 출고가 줄어든 원인을 가른다.** 시장이 줄었나, 우리가 뺏겼나 |

기간본이면 8절을 추가로 돈다.

## 0. 먼저 읽을 것

- `${CLAUDE_PLUGIN_ROOT}/references/data-sources.md` — **필수**
- `${CLAUDE_PLUGIN_ROOT}/references/segmentation.md` — **필수**

## 1. 조회 구간을 정한다

`mart.yes24_sales_daily`의 `model_version`을 먼저 확인하고 **단일 버전 구간**으로 자른다.
4개월 이상을 권한다. 짧으면 계절성에 끌려간다.

## 2. 후보를 전수로 긁는다

제품맵이나 기억에 의존하지 않는다. `raw.yes24_item_meta.subject`의 카테고리로 범위를 잡고
제목 패턴으로 걸러 **후보 전체**를 뽑는다. 쿼리 골격은 `data-sources.md`에 있다.

한 번에 끝내지 말고 패턴을 넓혀가며 두세 번 돌린다.

- 1차: 세그먼트 핵심 키워드
- 2차: 같은 콘셉트인데 다른 표현을 쓰는 것 (서술형 ↔ 영작·쓰기)
- 3차: 제목에 키워드가 없는 것을 찾기 위해 카테고리 전체를 판매량순으로 훑기

## 3. 목차를 확인한다

**판매량 상위 5종은 예외 없이 확인한다.** 출판사 공식 페이지 → 온라인 서점 상품 페이지 순.

확인할 것은 셋이다.

- 실제 구성이 우리 권별 위계의 어디에 대응하는가
- 대상 학년이 우리와 같은가
- 같은 시리즈의 다른 ISBN과 중복 등록은 아닌가

확인하지 못한 품목은 **목록에 "명칭 기준 분류"로 표시**하고 보고서 유의사항에 넘긴다.

## 4. 분류한다

권별 위계에 맞춰 두 계열로 나눈다. 애매한 묶음은 제외하지 말고 **토글 후보**로 뺀다.

```
core   : 검증 완료, 확실히 포함
toggle : 경계에 있음 (어법 중심 / 자사 폐간 예정 / 인접 콘셉트)
제외   : EBS 연계, 특정 레벨만 해당, 기출·평가문제집
```

## 5. TAM · SAM

- **TAM** — 카테고리 전체 합계. 제품맵이 아니다
- **SAM** — 검증 목록 합계
- `SAM / TAM` 비율을 계산한다. 10% 아래면 니치, 20% 위면 두터운 세그먼트다

## 6. 여기서 사용자 확인을 받는다

경쟁서 표를 **글자로** 보여준다. HTML을 만들지 않는다.

```
확인 부탁드립니다. 이 목록이 맞으면 계수 산출로 넘어갑니다.

[1단계] n종 · 합계 X부
  - 서명 (출판사) 000부   ← 목차 확인함
  - ...
[2단계] n종 · 합계 Y부
  - ...
[토글 후보]
  - 묶음명 n종 000부 — 포함 여부 판단 필요
```

자사 품목은 표시하고 현 점유율을 함께 적는다. 다음 단계의 목표 점유율 근거가 된다.

---

## 8. 기간본이면 — 연도별 추이까지 뽑는다

**한 시점의 점유율만으로는 원인을 가를 수 없다.** 세그먼트 합계와 자사 품목을 **연도별로**
뽑아 추이를 만든다. 최소 3개년.

```
             2024      2025      2026
세그먼트 계   00,000    00,000    00,000
자사 <품목>    0,000     0,000     0,000
자사 점유율     0.0%      0.0%      0.0%
```

조회 구간이 `model_version`에 걸리면 연도별 비교가 깨진다. **버전이 바뀐 지점을 확인하고,
걸치면 그 사실을 적는다.** 버전이 다른 구간끼리 비율만 비교하고 절대값은 비교하지 않는다.

경쟁 신간이 최근 2년 안에 들어왔으면 **출시 시점과 규모를 따로 적는다.**
자사 감소분과 그 신간의 증가분이 비슷하면 이탈 근거가 된다.

판정은 3단계(`project-demand`) 6절에서 한다. 여기서는 숫자만 만든다.

### 기간본의 사용자 확인 문구

```
확인 부탁드립니다.

[세그먼트] n종 · 2026년 합계 X부 (2024년 대비 0%)
  - 서명 (출판사) 000부  ← 목차 확인함
  - ...
[자사] <품목> 0,000부 · 점유율 0.0% (2024년 0.0% → 2025년 0.0%)
[최근 진입] <서명> (출판사) 2025년 출시 0,000부
```
