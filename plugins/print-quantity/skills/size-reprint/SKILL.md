# 소진 시점·수량 산출 (size-reprint)

## 0. 먼저 읽을 것

- `${CLAUDE_PLUGIN_ROOT}/references/reprint-model.md` — **필수**
- `${CLAUDE_PLUGIN_ROOT}/references/coefficients.md` 6절

3단계에서 받은 것: 가용재고, 월별 수요 곡선 `D(m)`, 계절지수, 성수기, 최소 로트.

---

## 1. 소진 시점과 발주 마감일

순출고 기준 수요로 재고를 깎아 나간다.

```
잔량(m) = 가용재고 + 미입고분 − Σ D(T ~ m)
소진 예상월 = 잔량이 처음 0 이하가 되는 달
발주 마감일 = 소진 예상월 − 리드타임 L
```

**발주 마감일이 오늘보다 앞이면 이미 늦은 것이다.** 결론 맨 위에 그대로 적는다.
"몇 부"보다 "언제까지"가 먼저 필요한 상황이다.

`L`은 3단계에서 제작팀에게 받은 확정값을 쓴다. 못 받았으면 1.5개월로 두고 **미확인이라고
적는다.** 소진 예상월이 성수기와 겹치면 제작처가 밀리므로 `L`을 1.5배로 보고 유의사항에 적는다.

---

## 2. 커버 기간 `C`를 정한다 — 성수기로 끊는다

개월 수를 먼저 정하지 않는다. **다음 성수기가 끝나는 달까지**가 기본이다.

```
C = (다음 성수기 종료월 − 입고 예정월) + 1
입고 예정월 = 오늘 + L
```

| 상황 | 커버 기간 |
|---|---|
| 기본 | 다음 성수기 종료까지 |
| 회전이 빠르고 로트가 작다 | 짧게. 재발주 횟수를 늘린다 |
| 폐간 검토 중 | 성수기 하나만. 그 뒤는 찍지 않는다 |

---

## 3. 수요 기준 수량

```
필요량   = Σ D(T ~ T+L+C) + 안전재고
안전재고 = Σ D(T ~ T+L) × SS          SS 기본 1.0
수요 기준 수량 = 필요량 − (가용재고 + 미입고분)
```

반품률이 높은 품목(총출고 대비 순출고 15% 이상 차이)은 `SS`를 0.5로 낮춘다.
반품이 실질적인 완충재고 역할을 한다.

---

## 4. 잔여 수명 상한 — 개정·폐간

`E` = 구판 판매 종료 시점. **1단계에서 확인받은 값이다. 없으면 이 절을 건너뛴다.**

```
잔여 수요       = Σ D(T ~ E) × r          r 기본 0.9, 개정 공지 후 0.8
잔여 수명 상한  = 잔여 수요 − (가용재고 + 미입고분)

제작 수량 = min(수요 기준 수량, 잔여 수명 상한)
```

상한이 걸렸으면 **사장 예상 재고를 반드시 계산한다.**

```
사장 예상 재고 = 가용재고 + 미입고분 + 제작 수량 − Σ D(T ~ E)
```

0보다 크면 그 부수만큼 폐기 위험이다. **결론 옆에 적는다.**
상한이 음수면 **찍지 않는다.** 지금 재고로 개정까지 간다는 뜻이다. 그렇게 보고한다.

---

## 5. 여기서 사용자 확인을 받는다

```
커버 기간과 개정 상한을 이렇게 잡았습니다.

  커버 기간   <n>개월 — 다음 성수기(<월>) 종료까지
  개정 예정   <연월> (확인받음) / 없음
  리드타임    <n>개월 (제작팀 확인 / 미확인)

  수요 기준   0,000부
  개정 상한   0,000부   ← 이쪽이 걸립니다
  제작 수량   0,000부   (사장 예상 재고 000부)

커버 기간을 조정할까요?
```

**보고서를 먼저 만들어놓고 확인받지 않는다.** 글자 표로 받는다.

---

## 6. 로트 반올림

```
산출값 → 백 단위 반올림 → 최소 로트 하한 → 천 단위 반올림
```

최소 로트는 3단계에서 실측한 값. 산출값이 그보다 작으면 **찍을지 말지 자체가 판단 대상이다.**
"최소 로트에 못 미친다"고 그대로 보고하고, 대안(다음 성수기까지 미루기)을 함께 적는다.

`Math.round`(0.5 올림) 기준으로 검산한다. 파이썬 `round`는 짝수로 내려 경계값에서 틀린다.
경계값이면 민감도를 기록해 보고서에 넣는다.

> 커버 기간을 1개월만 줄여도 3,000부로 떨어집니다.

---

## 7. 여러 종일 때

**종별로 따로 계산하고 따로 반올림한다.** 묶어 찍어 단가를 낮추는 판단은 제작팀 소관이다.
우리는 종별 필요량과 소진 시점을 주고, 묶음 여부는 제작팀이 정하게 한다.

다만 **소진 시점이 1개월 안에 몰려 있으면 그 사실을 표시한다.** 묶을 근거가 된다.
