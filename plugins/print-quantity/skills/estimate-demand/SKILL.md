# 수요·부수 산출 (estimate-demand)

## 0. 먼저 읽을 것

- `${CLAUDE_PLUGIN_ROOT}/references/channel-model.md` — **필수**
- `${CLAUDE_PLUGIN_ROOT}/references/coefficients.md`

## 1. 목표 점유율 시나리오

SAM 내 비중으로 잡는다. 세 가지를 만든다.

| 시나리오 | 기준 |
|---|---|
| 보수 | 자사 기존 품목의 현 점유율 수준 |
| **기준** | 현 점유율 + 신간 효과 + (폐간이면) 그 자리가 비는 효과 |
| 낙관 | 카테고리 2위권 진입 |

**2종이면 두 종의 범위를 같은 체계로 잡는다.** 한쪽만 좁게 잡으면 부수가 한쪽으로 쏠린다.
권장은 1단계 10~28%(기준 18%), 2단계 7~20%(기준 13%)다.

세그먼트 안에 **대상 학년이 어긋나는 대형 품목**이 있으면 그 물량에만 목표 점유율의
절반을 적용하고 가중평균한다. 실제로 뺏어오기 어려운 물량이기 때문이다.

## 2. 여기서 사용자 확인을 받는다

```
목표 점유율 기준값을 이렇게 잡았습니다.

  1단계 18%  (자사 기존 <품목> 현 11.6% → 폐간분 흡수 + 신간 효과)
  2단계 13%  (자사 기존 <품목> 현  5.8% → 동일)

이 값으로 첫해 수요 A / B부가 나옵니다. 조정할까요?
```

## 3. 첫해 수요

```
SAM(종별)  = 세그먼트 추정 판매량 ÷ K_EST × K_YEAR × K_SHIP
SOM        = SAM × 목표 점유율
첫해 수요   = SOM × K_FIRST
```

## 4. 채널 분해

```
온라인 = 첫해 수요 × ONLINE
총판   = 첫해 수요 × (1 − ONLINE)
```

## 5. 부수 — 분기를 판정한다

| 조건 | 산식 |
|---|---|
| 초도 배본 > 총판 첫해 수요 | `초도 배본 + 온라인 × K_PRINT` |
| 초도 배본 ≤ 총판 첫해 수요 | `첫해 수요 × K_PRINT` |

**확정된 초도 배본에는 `K_PRINT`를 걸지 않는다.** 수요에서 나오는 부분에만 건다.

반올림은 백 단위 → 천 단위 순으로 두 번 한다. 종별로 따로 반올림한다.

## 6. 검산

브라우저와 같은 반올림 규칙으로 확인한다. 파이썬 `round`는 0.5를 짝수로 내리므로
경계값에서 틀린다. Node로 검산하거나 `Math.round` 동작을 그대로 구현한다.

경계값이면 민감도를 기록해 보고서에 넣는다.
