## 1. 데이터 블록부터 채운다

템플릿 하단 `<script>`의 상수·배열을 먼저 채운다. HTML 본문의 숫자는 초기 표시값일 뿐이고,
실제 값은 `render()`가 계산한다. **둘이 어긋나면 새로고침할 때 숫자가 바뀐다.**

### 신간

```js
var BOOKS = [ {n, p, g, v, grp, c, us?, hard?}, ... ];
var TAM_EST = 0, K_EST = 0, K_YEAR = 0, K_SHIP = 0,
    K_FIRST = 0.75, K_PRINT = 0.75, ONLINE = 0, INIT = 0;
var SCENARIOS = [ {k, b, t, why, pick?}, ... ];
```

| 필드 | 뜻 |
|---|---|
| `g` | `"b"` 1단계 / `"t"` 2단계 |
| `grp` | 토글 그룹 키. `core`는 항상 켜짐 |
| `us` | 자사 품목. 막대에 검은 테두리가 붙는다 |
| `hard` | 대상 학년이 어긋나 목표 점유율 절반을 적용할 품목 |
| `INIT` | 확정 초도 배본. 분기 B면 쓰지 않는다 |

분기 A/B에 따라 `render()`의 `rawB` / `rawT` 계산식을 바꾼다. 템플릿에 두 가지가 주석으로 들어 있다.

### 기간본

```js
var TODAY = "2026-09";
var ITEMS = [ {key, name, stock, incoming, incomingAt, annual, g, lot, E?}, ... ];
var SEASON = [ .., 12개 월별 지수 .. ];   // 합 1
var LEAD = 1.5, SS = 1.0, R_REV = 0.9, COVER = {..종별 기본 개월..};
var WAREHOUSE = [ {name, qty, use}, ... ];   // use:false면 제외한 창고
var HISTORY  = [ {item, date, qty, months}, ... ];  // 제작 이력
```

| 필드 | 뜻 |
|---|---|
| `stock` | **가용재고.** 제외 창고를 뺀 값 |
| `incoming` | 미입고분. 없으면 0 |
| `annual` | 기준 연간 수요(순출고). 소진 시뮬레이션에 쓴다 |
| `g` | 노후화율 |
| `lot` | 최소 로트. 이력 실측값 |
| `E` | 개정·폐간 예정 (`"2027-01"`). 없으면 생략 → 상한 토글이 안 뜬다 |

`SEASON`의 합이 1이 아니면 `render()`가 정규화하지만, **1로 맞춰서 넣는다.**
합이 어긋나 있으면 계절지수 산출이 틀렸다는 신호다.

## 2. 섹션을 채운다

`report-spec.md`의 순서를 그대로 따른다. **순서를 바꾸지 않는다.**
기간본은 7절의 순서다 — 재고 → 추세 → 시장 → 소진 → 수량.

각 섹션 제목 오른쪽의 단위 배지를 잊지 않는다.
신간은 총출고 기준과 추정 기준을, 기간본은 총출고와 순출고를 다른 색으로 구분한다.

### 기간본에서 빠뜨리기 쉬운 것

- **결론에 날짜가 들어간다.** 소진 예상월과 발주 마감일. 부수만 적지 않는다
- **발주 마감일이 지났으면 색을 바꿔 경고한다.** 이 보고서에서 가장 중요한 한 줄이다
- **제외한 창고를 02에 그대로 보여준다.** 합계만 적으면 왜 이 재고인지 설명되지 않는다
- **상한에 걸렸으면 06 안에서** 수요 기준 수량과 나란히 보여준다. 유의사항으로 내리지 않는다
- **사장 예상 재고**를 결론 옆에 적는다

## 3. 검사한다

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/check_qty_report.py <파일경로>
```

스크립트가 데이터 블록을 보고 신간·기간본을 스스로 가른다. 검사 항목은 다음과 같다.

- `getElementById` 참조가 전부 HTML에 있는지, 중복 `id`가 없는지
- 스크립트 문법 오류 (`node --check`, node가 있으면)
- **초기 표시값과 `render()` 산출값이 일치하는지** — 가장 많이 틀리는 곳이다
- 본문에 남은 이전 버전 숫자 (계산값과 어긋나는 퍼센트 표기)
- 기간본이면 추가로 — 계절지수 합이 1인지, 가용재고가 제외 창고를 뺀 값과 맞는지,
  결론의 소진월·발주 마감일이 계산값과 같은지

실패하면 고치고 다시 돌린다. 통과 전에는 전달하지 않는다.

---

## 4. 숫자를 고쳤으면 문장도 고친다

품목 하나를 다른 계열로 옮기거나 창고 하나를 빼면 본문 서술이 전부 어긋난다.
검사 스크립트가 퍼센트 표기를 뽑아주므로 **하나씩 실제 값과 대조**한다.

자주 어긋나는 문장들이다.

- "자사 기존 품목의 현 점유율이 A% · B%"
- "○○사가 □□ 시장의 절반을 점유"
- "전년 대비 00% 감소"
- "재고의 00%가 폐기 창고에 있습니다"
- 섹션 제목 자체 ("Complete 시장이 Basic의 2배입니다")

`/mnt/user-data/outputs`에 저장하고 공유한다. 파일명은 갈래에 맞춘다.

| 갈래 | 파일명 |
|---|---|
