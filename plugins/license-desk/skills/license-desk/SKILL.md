# license-desk 흐름

대상: $ARGUMENTS

아래 순서대로 진행한다. 각 역할의 일은 해당 서브에이전트에게 맡기고 직접 하지 않는다.
외부 시스템(메일, 계약서 폴더, 전자결재) 접근은 이 흐름만 한다. 역할은 건 폴더 파일만 다룬다.
접근 순서와 폴백은 `${CLAUDE_PLUGIN_ROOT}/references/tools.md`를 따른다.

## 0. 준비

1. `${CLAUDE_PLUGIN_ROOT}/references/house-rules.md`와 `tools.md`를 읽는다
2. 저작권 폴더 위치를 정한다
   - 의존: 설정 파일 `.claude/license-desk.local.md`의 `copyright_folder:` 값
   - 없음 판단: 파일이 없거나 값이 비었거나 그 경로가 열리지 않으면
   - 대체: 사용자에게 경로를 묻고 설정 파일에 저장한다. 경로 접근이 안 되는 환경이면 M365 검색 경로로 진행하고 모든 산출물에 "PC 폴더 미접근" 표시
3. 업체 폴더를 찾는다: `<저작권 폴더>\계약서\<가장 최근 연도 폴더>\<업체>`. 없으면 만들지 말고 사용자에게 위치를 묻는다
4. 건 폴더를 만든다: `<업체 폴더>\_license-desk\<YYMMDD>_<임시>`. 유형이 정해지면 이름 뒤를 유형으로 바꾼다
5. 건 폴더에 `sources.md`를 만들고, 이후 자료를 어디서 가져왔는지(자동/대체/요청) 한 줄씩 적는다

## 1. 수집 → 문의 정리

1. 대상과 관련된 메일 스레드를 찾아 원문을 `00_mail.md`로 저장한다 (tools.md 표의 순서)
2. `license-intake`를 부른다. 넘길 것: 규칙 문서 경로 2개, 건 폴더 경로
3. 결과 `01_case.md`의 `건 유형:` 줄을 읽어 1차 분기한다

## 2. 1차 분기

| 건 유형 | 다음 |
|---|---|
| 신규 | 3 → 4 → 5(확인) → 6 → 7 |
| 갱신 | 3 → 4 → 4-1(2차 분기) |
| 침해 | 3 → 5(확인) → 6 → 7 |
| 후속 | 장부 조회(`ledger.py show`) → 6 → 7 |

## 3. 조회 → 계약 조회

1. 업체 폴더의 계약서·연장합의서, `★CP저작권 계약현황` 파일, 「저작권 계약 운영 원칙 및 기준」을 건 폴더 `_src\`에 복사한다. 원본은 열기만 한다
2. 침해 건이면 전자결재에서 해당 업체 결재 문서 목록도 `_src\edoc.md`로 저장한다
3. `license-contract-lookup`을 부른다 → `02_contract_facts.md`

## 4. 계산 → 조건 계산

1. `license-fee-calc`를 부른다 → `03_fee_input.json`, `03_fee_input_result.json`, `03_fee.md`, (갱신이면) `03_route_input.json`
2. `03_fee.md`의 확인 필요 목록에 '합산값'이 있으면 5단계 확인 때 함께 묻는다

### 4-1. 2차 분기 (갱신만)

`python ${CLAUDE_PLUGIN_ROOT}/scripts/route_renewal.py <건 폴더>`를 실행한다. 첫 줄로 판정한다.
- `ROUTE: 변동없음` → 5를 건너뛰고 6으로. 초안 종류는 계약연장합의서 + 갱신 안내 메일
- `ROUTE: 협의필요` → 5로. 출력된 사유를 확인 화면 맨 위에 둔다

## 5. 팀장 확인 (멈춤)

한 화면에 보여 준다: 건 카드 요약, 계약 사실 중 불일치, 금액표, 업체 제시값 대조표, 확인 필요 목록, (갱신) 분기 사유.
방향을 묻는다: 할인 여부, 기간, 업체 값 정정 여부, 만들 문서 종류.
답을 `05_direction.md`에 그대로 적는다. 답 없이 6으로 가지 않는다.

## 6. 작성 → 초안 작성

`license-drafter`를 부른다. 넘길 것: 건 폴더 경로, 5의 방향(없으면 "방향: 기본 규칙대로, 변동 없는 갱신").
결과: `06_reply.md`, 계약 문서 초안, 발송 전 내부 확인 사항.

## 7. 검수

1. `python ${CLAUDE_PLUGIN_ROOT}/scripts/calc_fee.py <건 폴더>/03_fee_input.json`을 다시 실행해 `07_recalc.md`로 저장한다
2. `license-reviewer`를 부른다. 넘길 것: 건 폴더 경로
3. 응답 전체를 `07_review_<n>.md`로 저장한다
   - `VERDICT: FAIL` → 검수 파일 경로를 넘겨 `license-drafter`를 다시 부르고 다시 검수한다. **2회 다시 써도 FAIL이면 멈추고** 마지막 불합격 사유와 함께 사용자에게 넘긴다
   - `VERDICT: PASS` → 8로

## 8. 기록 → 진행 기록

`license-tracker`를 부른다. 넘길 것: 건 폴더 경로, 장부 경로(`<저작권 폴더>\license-desk_진행장부.xlsx`), 기록할 단계 6(초안 완료).

## 9. 전달

사용자에게 보여 준다: 건 폴더 위치, 초안 파일 목록, 발송 전 내부 확인 사항, 다음 단계(법무 검토 요청).
메일을 보내거나 결재를 올리지 않는다.

## 파일 규칙

- 번호는 단계 순서다. 다시 쓴 초안은 `06_reply_r2.md`처럼 덧붙이고 앞 파일을 지우지 않는다
- 건 폴더는 OneDrive에만 둔다. 플러그인 레포에 복사하지 않는다
