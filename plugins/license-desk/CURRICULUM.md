# license-desk: 하네스 진행 기록

## 목표

업체의 저작물 이용 문의·갱신 요청·침해 사례를, 기존 계약과 표준사용료로 검증된 회신·계약서 초안과 단계별 진행 기록(법무 검토 → 업체 송부 → 양사 품의 → 날인 → 입금)으로 바꾸는 체계. 팀장이 매 단계를 직접 챙기지 않아도 됨.

---

## 업무 파악 (0단계 결과)

- 범위: 신규 이용 문의, 기존 계약 갱신, 침해 대응, 계약 후속(날인·세금계산서·입금)
- 근거 자료: OneDrive `201. 저작권_CP계약관리\계약서` (연도별 폴더, 계약서#번호), 표준사용료, 매출 규모별 할인율(1억 미만 87.5% / 10억 미만 75% / 30억 미만 50%)
- 계약 원칙: 수강생 수와 무관한 1년 단위 정액(턴키), 매출 규모별 할인
- 진행 절차: 문의 확인 → 기존 계약서 확인 → 조건 계산 → 상대 제시값 대조 → 회신·계약서 초안 → 법무 검토 → 법무 검토안 업체 송부 → 업체 OK → 양사 품의 → 양사 품의 통과 후 날인 → 세금계산서·입금
- 금지 규칙
  - 근거 없는 값 채우기 (빈칸+TODO로 남김)
  - 확인 없이 발송 (초안까지만)
  - 기준이 다른 숫자 비교
  - 복기할 수 없는 계산 (산출 로직을 사용자가 따라갈 수 있게 남김)
  - 협상 여지 표현 (할인 불가 건에서)
  - 내부 기준에 없는 할인·조건 자체 제안
  - 계약서 원본 수정 (항상 새 파일)
  - 상대 제시값을 대조 없이 수용
  - 절차 건너뛰기 (법무 검토 전 송부, 품의 전 날인 등)
