# 문서·슬라이드 렌더링 (build-doc)

`report-spec.json`을 회의에서 넘기며 설명하거나 결재 문서에 붙일 형태로 만든다.
스펙에 없는 결론을 새로 만들지 않는다.

## 0. 먼저 읽을 것

- `${CLAUDE_PLUGIN_ROOT}/references/design-rules.md`
- 산출 포맷에 맞는 문서 스킬 (`pptx` / `docx`) — **스펙이 확정된 뒤에** 읽는다

## 1. 포맷 선택

| 요청 신호 | 포맷 |
|---|---|
| "발표", "회의에서 넘기며", "보고 자리" | 슬라이드 (.pptx) |
| "문서로", "결재", "붙여넣을 것" | 문서 (.docx) |
| "정리만 해줘", 내부 공유 | Markdown (.md) |

모르면 묻는다.

## 1-1. 스펙 2.0 요소를 문서에서 어떻게 다루나

| 스펙 요소 | 슬라이드 | 문서 |
|---|---|---|
| `key_takeaway` | 표지 다음 장에 한 문장, 가장 큰 글자. `emphasis`는 굵게·색으로 | 첫 줄 |
| `kpis` | 요약 장에 한 줄로 | 첫 문단 아래 표 |
| `actions` | **마지막 직전 장에 "인사이트와 액션"** 한 장 | 본문 끝 섹션 |
| `glossary` | **마지막 장에 용어 정리** | 문서 끝 용어 정리 |
| `calcs` | 해당 exhibit 각주 또는 부록 장 | 해당 각주 또는 부록 |
| `group_detail` | **부록 장에 전체 표** (모달이 없으므로) | 부록 표 |

문서·슬라이드에는 툴팁과 모달이 없다. **숨길 곳이 없으므로 부록으로 뺀다.**
`group_detail`을 아예 빼면 묶인 데이터가 사라진다. 반드시 부록에 넣는다.

## 2. 슬라이드 규칙

- **슬라이드 1장 = exhibit 1개.** 두 개를 한 장에 넣지 않는다.
- **`action_title`이 슬라이드 제목이다.** 글자 그대로 쓴다. 줄여서 명사구로 만들지 않는다.
- 구성: 제목(action_title) → 차트 → so_what 한 줄 → 각주 4요소
- 표지 다음 장은 **헤드라인 한 문장 + 요약 3줄**. 목차는 exhibit이 5개를 넘을 때만.
- 마지막 장에 공통 각주와 `open_questions`.

슬라이드 수 = 1(표지) + 1(요약) + exhibit 수 + 1(인사이트·액션) + 1(각주) + 부록(group_detail·용어).

## 3. 문서 규칙

- 맨 앞에 헤드라인 한 문장. 그 아래 요약 3줄.
- exhibit마다 `## action_title` → 차트 이미지 → so_what → 각주.
- 표 exhibit은 이미지가 아니라 실제 표로 넣는다. 복사해서 쓸 수 있어야 한다.
- 각주는 각 exhibit 바로 아래. 문서 끝에 몰아두지 않는다.

## 4. 차트 이미지

- 스펙의 `data.rows`로 차트를 그려 PNG로 만든 뒤 삽입한다 (matplotlib 등).
- 한글 폰트가 깨지지 않게 폰트를 지정한다. 깨지면 그대로 넣지 말고 해결하거나 표로 대체한다.
- 색은 `design-rules.md`의 토큰과 같은 계조를 쓴다. 기본 팔레트를 그대로 쓰지 않는다.
- 막대는 y=0 시작. 금칙 차트는 렌더링하지 않고 대안으로 바꾼 뒤 알린다.
- 해상도는 슬라이드 기준 최소 150dpi.

## 5. 기준 표기

- 표지(또는 문서 첫 줄)에 `기준: <basis> · <기간> · 단위 <unit>`을 넣는다.
- exhibit의 `basis`가 최상위와 다르면 그 장에 명시적으로 표시한다.

## 6. 검수

- [ ] 슬라이드 제목이 스펙의 `action_title`과 글자 그대로 일치하는가
- [ ] 한 장에 exhibit이 2개 이상 들어간 장이 없는가
- [ ] 모든 exhibit에 각주 4요소가 있는가
- [ ] 차트의 한글이 깨지지 않았는가
- [ ] 막대 차트가 0에서 시작하는가
- [ ] `open_questions`가 마지막 장(또는 문서 끝)에 있는가
- [ ] `actions`가 한 장으로 들어갔는가 (report 모드)
- [ ] `group_detail`이 부록 표로 들어갔는가
- [ ] `glossary`가 용어 정리로 들어갔는가
- [ ] 한국어가 단어 중간에서 잘리지 않는가 (차트 이미지 라벨 포함)

## 7. 전달

- 파일명: `<주제>_<기간>_<기준>.pptx`
- 작업 폴더에 저장하고 사용자에게 전달한다.
- 수정 요청이 오면 **스펙을 고치고 다시 렌더링한다.** 산출물을 직접 편집하지 않는다.
