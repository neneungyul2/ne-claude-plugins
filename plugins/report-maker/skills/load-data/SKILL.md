# 데이터 불러오기 (load-data)

어떤 경로로 들어온 데이터든 이 단계를 통과하면 **정규화 데이터셋 + 데이터셋 카드**가 나온다.
다음 단계(`plan-report`)는 이 두 가지만 본다.

## 1. 어댑터 선택

| 입력 | 어댑터 | 참조 문서 |
|---|---|---|
| .xlsx / .xls | excel | `${CLAUDE_PLUGIN_ROOT}/references/sources/excel.md` |
| .csv / .tsv | csv | 위 문서의 CSV 절 |
| 대화창에 붙여넣은 표 | paste | `${CLAUDE_PLUGIN_ROOT}/references/sources/paste.md` |
| Metabase 카드·SQL | metabase | `${CLAUDE_PLUGIN_ROOT}/references/sources/metabase.md` |

해당 참조 문서를 Read로 읽고 그 주의사항을 적용한다. 여러 소스를 합쳐야 하면 각각 정규화한 뒤
결합하고, 결합 키와 결합 후 행 수 변화를 데이터셋 카드에 남긴다.

## 2. 정규화 결과물

### 정규화 데이터셋

- 1행 = 1관측. 헤더는 한 줄. 병합 셀 없음.
- 소계·합계·공백 행 제거 (제거한 행 수를 기록)
- 컬럼별로 타입을 확정: 날짜 / 범주 / 수치
- 수치 컬럼은 **단위를 확정**한다. 원인지 천원인지 백만원인지 모르면 그대로 두지 말고 확인한다.
- 날짜는 ISO(YYYY-MM-DD)로 통일

원본이 크면 요약 통계와 필요한 컬럼만 남긴 파일을 따로 만든다. 원본은 건드리지 않는다.

### 데이터셋 카드

아래 9개 항목을 채운다. 모르는 항목은 **비워두고 "확인 필요"라고 쓴다.** 추정으로 채우지 않는다.

```
출처        (파일명 / Metabase 카드 번호 / 붙여넣기)
기간        YYYY-MM-DD ~ YYYY-MM-DD
단위        원 / 천원 / 부 / 건 ...
행 수       정규화 후 N행 (원본 M행, 소계·공백 K행 제거)
집계 기준   총출고 / 순출고 / 순출고(초도 제외) / 미확인
추출 시각   데이터를 뽑은 시점 (파일 수정일 또는 쿼리 실행 시각)
결측        컬럼별 결측 수
이상치      음수·0·극단값 등 눈에 띄는 것
주의사항    합산하면 중복되는 스냅샷 테이블 등
```

이 카드는 최종 산출물의 각주에 그대로 들어간다.

## 3. 집계 기준 확정

`${CLAUDE_PLUGIN_ROOT}/references/metrics.md`를 읽고 데이터가 어떤 기준인지 판정한다.

- 판정되면 카드에 적는다.
- 판정이 안 되면 **"미확인"으로 적고 사용자에게 한 번 묻는다.** 임의로 정하지 않는다.
- 기준이 여러 개 섞여 있으면(예: 채널별로 SCM/BNK 기준이 다름) 섞였다는 사실 자체를 카드에 쓴다.

기준을 모른 채 그린 차트는 틀린 차트다.

## 4. 실패 경로

### Metabase 접근 불가

Metabase는 **사내망 전용**이다. 실패했다고 작업을 중단하지 않는다.

1. 실패 원인을 구분해 안내한다.
   - 연결 자체가 안 됨 → 사내망 밖이거나 MCP 미설정
   - 연결은 되는데 특정 DB·스키마에서 거부 → 권한 문제 (`grp_<db>_<schema>_<permission>` 그룹)
   - 쿼리는 도는데 결과가 비정상 → 쿼리 문제. 분할 조회 시도
2. 대체 경로를 제시한다.
   > "Metabase에 접근이 안 됩니다(사내망 전용). 결과를 복사해서 붙여넣어 주시거나, 엑셀로
   > 내려받아 올려주시면 그대로 진행하겠습니다."
3. 붙여넣기·엑셀로 받으면 해당 어댑터로 계속 진행한다.

### 파일이 깨지거나 읽히지 않음

시트 목록과 첫 20행을 보여주고 어느 시트·어느 범위인지 확인한다. 추측해서 진행하지 않는다.

## 5. 반복되는 양식은 소스 프로파일로 저장

같은 양식의 엑셀을 매번 받는다면 헤더 위치·컬럼 매핑·단위를 **사용자 작업 폴더**에
`.report-source-<이름>.json`으로 저장하고 다음부터 재사용한다.

```json
{
  "name": "월별 채널 출고",
  "sheet": "출고",
  "header_row": 3,
  "skip_rows_containing": ["소계", "합계"],
  "columns": { "채널": "channel", "수량": "qty" },
  "unit": "부",
  "basis": "순출고"
}
```

이 파일은 **플러그인이 아니라 사용자 자산**이다. 플러그인 참조 문서에 양식을 박지 않는다.
