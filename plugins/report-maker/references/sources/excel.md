# 엑셀 / CSV 어댑터

엑셀 어댑터의 실제 역할은 파일을 읽는 게 아니다.
**두 줄 헤더, 소계 행 혼입, 단위 불명 상태로 차트가 그려지는 것을 막는 것**이다.

---

## 1. 순서

1. **시트 목록**을 먼저 확인한다. 시트가 여러 개면 어느 시트인지 확정하고 시작한다.
2. **첫 20행을 원본 그대로** 본다. 바로 `header=0`으로 읽지 않는다.
3. 헤더 행 위치를 찾는다. 제목·작성일·로고가 위에 몇 줄 있는 경우가 대부분이다.
4. 아래 함정을 하나씩 확인한다.
5. 정규화하고 데이터셋 카드를 채운다.

---

## 2. 함정 목록

### 두 줄 헤더 / 병합 셀

```
        │  2026년 8월   │  2026년 7월
 채널    │ 출고 │ 반품  │ 출고 │ 반품
```

- 상위 헤더를 하위 헤더에 내려 붙여 한 줄로 만든다: `2026-08_출고`, `2026-08_반품`
- 병합 셀은 빈칸으로 읽히므로 앞 값으로 채운다(forward fill)
- 붙인 뒤 **long 형태로 녹인다**(melt). 차트는 wide보다 long에서 안전하다

### 소계·합계 행 혼입

- "소계", "합계", "계", "총계", "Total", "小計"를 포함한 행을 제거한다
- 빈 행, 구분선 행, 비고 행 제거
- **제거한 행 수를 기록한다.** 합계 행을 하나 남기면 차트가 통째로 틀어진다
- 제거 후 합계가 원본 합계 행과 맞는지 대조한다. 안 맞으면 멈추고 원인을 찾는다

### 단위 불명

- 헤더나 셀에 `(천원)`, `(백만원)`, `단위:` 표기가 있는지 본다
- 없으면 값의 자릿수로 추정하되 **추정임을 밝히고 사용자에게 확인한다**
- 원/천원을 잘못 잡으면 1000배 틀린 보고서가 나간다
- 확인 전에는 데이터셋 카드에 `단위: 확인 필요`로 둔다

### 숫자가 문자로 저장됨

- 쉼표, 공백, `-`, `()`(음수), 전각 숫자, 따옴표 제거 후 숫자로 변환
- `(1,234)` → `-1234`
- 변환 실패한 셀은 0으로 바꾸지 않는다. 결측으로 두고 개수를 카드에 적는다

### 날짜

- 엑셀 일련번호(45000 같은 값), `2026.08.01`, `26/8/1`, `8월` 등이 섞인다
- ISO(YYYY-MM-DD)로 통일한다
- `8월`처럼 연도가 없으면 파일명·시트명·다른 컬럼에서 연도를 찾는다. 못 찾으면 묻는다

### 필터·숨김

- 숨겨진 행·열에 값이 있을 수 있다. 전체를 읽는다
- 피벗 테이블 결과 시트는 원본 시트를 찾아 쓴다

---

## 3. CSV 추가 주의

- 인코딩: UTF-8, CP949(EUC-KR)를 모두 시도한다. 한글이 깨지면 인코딩 문제다
- 구분자: `,` `\t` `|` 확인
- BOM 제거
- 따옴표 안에 쉼표가 들어간 필드 주의
- 큰 파일은 전체를 메모리에 올리기 전에 행 수와 컬럼을 먼저 확인한다

---

## 4. 정규화 후 자체 점검

- [ ] 헤더가 한 줄인가
- [ ] 소계·합계 행이 0개인가
- [ ] 수치 컬럼의 타입이 전부 숫자인가
- [ ] 단위가 확정되었는가 (아니면 "확인 필요"로 표시했는가)
- [ ] 날짜가 ISO 형식인가
- [ ] 정규화 후 합계가 원본 합계와 일치하는가
- [ ] 행 수 변화를 카드에 기록했는가

---

## 5. 반복되는 양식

같은 양식을 매번 받는다면 헤더 위치·컬럼 매핑·단위를 사용자 작업 폴더에
`.report-source-<이름>.json`으로 저장하고 다음부터 재사용한다.

**이 양식을 플러그인 참조 문서에 적지 않는다.** 사용자 자산이지 플러그인 자산이 아니다.
