지표 하나에 **복수 기준이 공존**한다. 특정 기준을 강제하지 않는다.
강제하는 것은 **어떤 기준을 썼는지 명시하는 것**이다.

> **이 문서를 쓰는 방법**
> - 확인된 것만 적는다. **확인이 안 된 항목은 빈칸으로 두고 `TODO`로 표시한다. 추정으로 채우지 않는다.**
> - 조회하면 알 수 있는 것(테이블 목록, 컬럼명, 시트 구성)은 적지 않는다. 런타임에 조회한다.
> - 적을 것은 조회로는 알 수 없는 **판단**이다. "이 테이블은 일 스냅샷이라 합산하면 중복" 같은 것.

## 1. 출고량

```
출고량
├ 총출고              SAP 매출수량 전량
├ 순출고              총출고 − 반품
├ 순출고(초도 제외)   신간 초도배본 물량 제외. 기존 종의 수요를 볼 때
├ 기본값              순출고. 반품은 항상 별도 표기하고 총출고에서 빼서 숨기지 않는다
└ 소스                Metabase mart 계열 우선. 엑셀 수불자료도 동일 정의로 계산
```

확인된 방침

- 출고량은 **SAP 매출수량 기준**이다.
- **반품은 별도 표기**한다. 순출고 하나만 보여주고 반품을 감추지 않는다.
- **종별 총출고량 집계 시 초도배본 물량은 제외**한다.

## 2. 실판매량 (실판매수량)

자타사 주요도서 점유율 자료 기준. **출고량과 다른 지표다.** 섞어 쓰지 않는다.

```
실판매량
├ YES24 단독      YES24만. 연도 비교용 채택 기준
├ 온라인 4채널    YES24 + 교보(온라인) + 알라딘(온라인) + 영풍(온라인)
├ 기본값          YES24 단독
└ 소스            book_actual_sales (DB3) — mart.actual_sales_monthly / actual_sales_daily
```

확인된 판단

- **전 기간(2022~2026) YES24 단독 기준으로 통일**한다. 그래머존의 비YES24 채널 결측 때문에
  4채널 기준으로는 연도 비교가 불가능하다.
- 원본 「자타사주요도서_점유율」 파일은 4채널 기준이므로 **두 파일의 2025·2026년 값은 서로 다르다.**
  나란히 놓을 때 반드시 기준을 표기한다.
- 두 기준 모두 **교보 오프라인 / 영풍 오프라인 / 지역서점(LOCAL) 제외**.
- **비YES24 채널 데이터 시작 시점이 도서마다 다르다.**
  - 그래머존 구판 6종: 2024-07-01부터 (그 전은 4채널 기준으로 과소집계)
  - 능률보카 어원편 Lite(중등): 2022-10부터 (출시 시점)
  - 능률보카 어원(21)(고등): 2021-09부터 정상
- **2021년 구간은 산출 불가.** YES24 2021-01~08은 행은 있으나 판매수량 전부 0.
  실질 개시 2021-09-01. 21-22 증감률은 어떤 기준으로도 산출할 수 없으므로 항목에서 제외한다.
- 세대 구분: 그래머존은 2025년 개정. **2022~2025년은 구판(2016년판) 기준**으로 집계한다.
  2026년은 신판만 집계한다(구판 잔여분 제외).
- 능률보카 어원편 중등은 2022-10 출시라 2022년 값이 없다. 어원 계·전체 합계의 22-23 증감률에
  왜곡이 있으므로 각주로 밝힌다.

## 7. 기준이 바뀌면 결론도 바뀐다

"총출고 기준으로 다시"라는 요청이 오면

1. 스펙의 `basis`를 바꾸고
2. **모든 `action_title`을 다시 계산해서 다시 쓴다**
3. 각주의 집계기준을 갱신한다

`basis`만 바꾸고 제목을 그대로 두면 틀린 산출물이 된다.
