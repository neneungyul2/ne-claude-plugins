# 한국 지도 (korea-map)

지역 데이터를 다룰 때 쓴다. **지역명 막대 차트만으로는 분포가 안 보인다.**

---

## 1. 자산

`${CLAUDE_PLUGIN_ROOT}/assets/korea_paths.json`

```json
{
  "viewBox": "0 0 520.0 551.3",
  "paths": { "서울": "M198.8,93.0 …", "부산": "…", …17개 시도… },
  "muni": {
    "서울": { "viewBox": "0 0 320.0 262.7", "paths": { "종로구": "…", … } },
    …17개 시도…
  }
}
```

- 시도 17개 · 시군구 전체를 담고 있다 (전체 441KB, 시도만 쓰면 72KB)
- 좌표는 이미 화면 좌표계로 투영되어 있다. 변환이 필요 없다
- **필요한 부분만 인라인한다.** 시도 지도면 `paths`만, 시군구 드릴다운이면 해당 시도의 `muni`만
- `Read` 도구로 읽으면 파일이 커서 낭비다. 파이썬으로 필요한 키만 뽑아 HTML에 넣는다

```python
import json
d = json.load(open(f"{PLUGIN_ROOT}/assets/korea_paths.json", encoding="utf-8"))
sido = {"viewBox": d["viewBox"], "paths": d["paths"]}          # 72KB
seoul = d["muni"]["서울"]                                       # 한 시도만
```

### 시도 이름 표기

자산의 키는 **단축형**이다. 데이터의 표기를 여기에 맞춰야 매칭된다.

```
서울 부산 대구 인천 광주 대전 울산 세종
경기 강원 충북 충남 전북 전남 경북 경남 제주
```

원본 데이터가 `서울특별시`·`경기도`·`충청북도`처럼 들어오면 정규화한다.
매칭 실패한 키는 **버리지 말고** 목록으로 남겨 각주와 `open_questions`에 올린다.
(`시도 미상` 같은 행이 흔히 있다.)

## 2. 기본형 — 지도 + 표

지도는 **분포**를, 표는 **정확한 값**을 담당한다. 둘 중 하나만 두지 않는다.

```html
<div class="maprow">
  <div>
    <div class="kmap">
      <svg viewBox="0 0 520 551.3" role="img" aria-label="시도별 매출">
        <path d="M198.8,93.0 …" fill="#3182f6" data-key="서울"
              data-tip="서울|매출 99.5백만원|비중 18.2%"/>
        …
      </svg>
    </div>
    <div class="scale">
      <span>낮음</span>
      <i style="background:linear-gradient(90deg,#e8f3ff,#1b64da)"></i>
      <span>높음</span>
      <span style="margin-left:6px">5.7 ─ 165.4 백만원</span>
    </div>
  </div>
  <div class="tw"><table>
    <thead><tr><th>지역</th><th class="r">매출</th><th class="r">비중</th></tr></thead>
    <tbody>
      <tr data-key="경기"><td>경기</td><td class="r">165.4</td><td class="r">30.3%</td></tr>
    </tbody>
  </table></div>
</div>
```

- `data-key`를 지도 `path`와 표 `tr` 양쪽에 같은 값으로 넣는다. 템플릿 스크립트가 연동한다
- 표는 값 내림차순 정렬. 지도는 순서가 없으므로 순위는 표가 답한다
- 표가 길면 상위 10~12개 + 기타로 묶고 `group_detail`을 채운다

---

## 3. 색 계조

```
5단계:  #e8f3ff  #c9defb  #8bb8f5  #4a90ec  #1b64da
```

- **5~7단계.** 연속 그라데이션은 값을 못 읽는다
- 구간은 분위수(quantile)로 나눈다. 등간격은 한두 지역이 몰린 데이터에서 전부 같은 색이 된다
- 값이 없는 지역은 `#f2f4f6` + 범례에 "데이터 없음" 표기. **0으로 칠하지 않는다**
- 증감률처럼 양·음이 갈리는 값은 발산 계조를 쓴다 — 감소 `#f04452` 계열 / 0 `#f2f4f6` / 증가 `#00b25b` 계열

---

## 4. 라벨

- 시도 지도는 **면적이 넉넉한 곳에만** 이름을 넣는다. 서울·대전·광주·울산·세종은 겹치므로 생략하고 툴팁에 맡긴다
- 폰트 9px, `--sub` 색, `pointer-events:none`
- 값은 지도에 쓰지 않는다. 표와 툴팁이 담당한다

---

## 5. 시군구 드릴다운

시도를 클릭하면 그 시도의 시군구 지도로 내려간다.

- 시군구는 개수가 많아 **지도만으로는 못 읽는다.** 상위 N개 표를 반드시 같이 낸다
- 해당 시도의 `muni[시도]["viewBox"]`를 쓴다. 시도마다 viewBox가 다르다
- 돌아가기 버튼을 둔다
- 드릴다운이 필요 없으면 넣지 않는다. 시군구 분석은 대부분 표로 충분하다

---

## 6. 착시 주의

- **면적이 큰 지역이 값도 커 보인다.** 경북·강원이 실제보다 크게 읽힌다. 표를 반드시 함께 둔다
- 인구 차이를 보정하지 않은 절대값 지도는 인구 지도와 거의 같아진다.
  "어디가 많이 팔리나"가 아니라 "어디가 유독 많이/적게 팔리나"를 묻는 것이라면
  **1인당·가구당 또는 전국 평균 대비 지수**로 바꿔 그린다. 그 경우 각주에 보정 기준을 명시한다

## 7. 검수

- [ ] 데이터의 시도명이 자산 키와 모두 매칭됐는가 (미매칭 목록을 각주에 남겼는가)
- [ ] 지도와 표의 `data-key`가 같은 값인가
- [ ] 범례에 양 끝 값과 단위가 있는가
- [ ] 값 없는 지역이 0과 구분되는가
- [ ] 표가 정렬돼 있는가
- [ ] 묶은 항목에 `group_detail`이 있는가
- [ ] 절대값 지도라면, 인구 보정 없이 읽어도 되는 질문인지 각주에서 짚었는가
