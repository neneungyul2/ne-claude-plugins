# 지식화 (kb-atomize)

원문을 **atomic 노트**로 분해해 vault에 쌓는다.

## 0. 먼저 읽을 것

`${CLAUDE_PLUGIN_ROOT}/skills/kb-conventions/SKILL.md` — 노트 타입, frontmatter, 관계 어휘, 폴더 체계.
규칙을 기억에 의존해 쓰지 않는다.

vault 경로는 `~/.knowledge-notes/config.json`에서 읽는다. 없으면 한 번 묻고 만든다.

---

## 1. 원문 투입

원문이 무엇인지 확정한다.

- 파일 → 읽는다
- 대화 맥락 → 어디부터 어디까지인지 확인한다
- URL → 가져온다
- 길면 `000_inbox/`에 원문을 먼저 저장하고 시작한다

---

## 2. 후보 추출 → 분류

원문에서 남길 가치가 있는 것을 뽑아 3가지로 나눈다.

| 분류 | 뽑는 기준 |
|---|---|
| `term` | 정의가 필요한 용어. 특히 **사내에서 다르게 쓰는 것** |
| `concept` | "왜 그런가", "어떻게 작동하는가"에 답하는 것 |
| `insight` | 우리 상황에 적용한 판단. 원문에 없고 **내가 내린 결론**도 여기 |

남기지 않을 것

- 일회성 사실 (이번 주 회의 시간, 특정 파일 경로)
- 검색하면 5초 안에 나오는 일반 상식
- 원문을 그대로 옮긴 요약 — 그건 `source` 노트의 역할이다

후보를 사용자에게 **목록으로 먼저 보여주고** 진행한다. 10개를 넘으면 우선순위를 묻는다.

---

## 3. 기존 vault 검색 + alias 대조 ← **이 스킬의 존재 이유**

노트를 만들기 **전에** 반드시 한다. 이 단계가 없으면 템플릿과 다를 바 없고, 유사 노트가 계속 생긴다.

1. 후보 제목으로 파일명 검색
2. **`aliases` 필드 검색** — 국문/영문/약어가 다르게 적혀 있을 수 있다
3. 본문 전문 검색 — 다른 노트 안에 이미 설명되어 있을 수 있다
4. 유사어 검색 — "재고회전율" ↔ "재고 회전율" ↔ "turnover" ↔ "ITR"

판정

| 결과 | 처리 |
|---|---|
| 같은 개념의 노트가 있다 | **기존 노트를 보강**한다. 새 표기를 `aliases`에 추가한다 |
| 비슷하지만 다른 개념이다 | 새로 만들고 `대조::`로 연결한다 |
| 없다 | 새로 만든다 |
| 애매하다 | 사용자에게 기존 노트를 보여주고 묻는다 |

**기존 노트를 보강할 때 기존 내용을 지우지 않는다.** 추가하거나 고칠 뿐이다.

---

## 4. 원자 단위로 분해

- 제목에 "그리고"가 있으면 쪼갠다
- 제목만 보고 내용이 예측되는가 확인한다
- `concept`·`insight`의 제목은 **문장**으로 쓴다
- `term`은 정의만, `concept`은 설명만, `insight`는 판단만

---

## 5. 노트 작성

`${CLAUDE_PLUGIN_ROOT}/templates/`의 타입별 템플릿을 사용한다.

- frontmatter 전체를 채운다. `aliases`를 비워두지 않는다
- `status: seed`로 시작
- `created`는 오늘 날짜
- 타입에 맞는 폴더에 저장한다
- 원문이 있으면 `source` 노트를 하나 만들고 나머지 노트에서 `근거::`로 건다

### 링크 연결

- 관계 어휘 6개만 쓴다
- **본문 안에서 링크할 때는 왜 연결했는지 한 문장을 같이 쓴다**
- 아직 존재하지 않는 노트도 `[[ ]]`로 건다. 그게 다음 단계의 입력이 된다

---

## 6. 빈 링크 리포트 — **버그가 아니라 자산**

작업이 끝나면 **아직 노트가 없는 링크 목록**을 출력한다.

```
빈 링크 4개 — 다음에 정리할 후보

  [[안전재고]]       3개 노트에서 참조됨  ← 우선순위 높음
  [[리드타임]]       2개 노트에서 참조됨
  [[BNK]]           1개 노트에서 참조됨
  [[초도배본]]       1개 노트에서 참조됨
```

참조 횟수 순으로 정렬한다. **참조가 많은 빈 링크가 곧 다음에 정리할 것의 우선순위다.**

---

## 7. 마무리 보고

```
새 노트 5개 (term 3, concept 1, insight 1)
기존 노트 보강 2개 — [[재고회전율]] (alias 추가), [[품절]] (사내 정의 채움)
빈 링크 4개 → 위 목록
확인 필요 2건 — 사내 정의 미확인: [[반품률]], [[재고일수]]
```

사내 정의를 모르는 항목은 **일반 정의로 채우지 말고 TODO로 남긴 뒤 여기에 보고한다.**
