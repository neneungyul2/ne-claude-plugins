# 온라인 4채널 기준

> YES24 + 교보(온라인) + 알라딘(온라인) + 영풍(온라인)을 합산한 실판매량 기준.

## 사내 정의
- 원본 「자타사주요도서_점유율」 파일이 쓰는 기준.
- 비YES24 채널의 데이터 시작 시점이 도서마다 달라 **연도 비교에는 쓸 수 없다.**
  (그래머존 구판 6종은 2024-07-01부터 수집)
- 교보 오프라인 / 영풍 오프라인 / 지역서점(LOCAL) 제외.

## 혼동 주의
- [[실판매량]] — YES24 단독 기준. 같은 연도라도 값이 다르다
